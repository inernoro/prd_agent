# 设计稿还原度取证流水线

把设计稿画布切成一块块基准图，把实现渲染成同编号的对照图，交给审查智能体逐块打分。
判分规则与输出格式在 `.claude/agents/design-fidelity-judge.md`；工程看板与当前成绩在
`doc/plan.prd-admin.recording-design-restoration.md`。

## 为什么要先剥掉设计稿的运行时

设计稿画布（`*.dc.html`）会在浏览器里等一个远端加载的运行时，拿不到就把静态内容藏起来。
沙箱访问不到那个源，所以取证前要生成一份去掉运行时依赖的静态副本再切图，
否则截出来的是一整页空白——而空白页同样能跑完流程、同样能出分数，
这正是「不会红的证据比没有证据更糟」。

## 跑法

**先说清一件事：设计稿画布不在本仓库里。** 它是设计方的交付物，跑这条流水线之前
要自己把那个目录起成静态服务，再用环境变量指过去。不指就用默认值
（`http://localhost:8188`，两块画布 `delivery-v2.html` / `capture-and-result.html`）。
取不到时脚本会当场报错说清缺什么，不会静默切出一批空白基准图。

```bash
# 1. 把设计稿目录起成静态服务，并生成去运行时的静态副本
#    默认地址 http://localhost:8188；换地址或换文件名用：
#      DESIGN_BASE_URL=http://localhost:9000 \
#      DESIGN_PAGES='delivery-v2.html:v2,capture-and-result.html:cap' \
#    浏览器默认让 Playwright 自己找，要指定就给 CHROMIUM_PATH
# 2. 切设计稿基准图
node e2e/design-fidelity/extract-design-boards.mjs
# 3. 起对照台（prd-admin 目录下 pnpm exec vite --port 8123），再取实现图
node e2e/design-fidelity/shoot-impl-boards.mjs
# 4. 取**真实应用**的图（同一个 8123，走真实入口而不是对照台）
node e2e/design-fidelity/shoot-real-app.mjs
# 5. 逐块交给审查智能体打分（基准图 + 实现图 + 画板编号）
```

## 对照台的图不能代替真实页面的图

`shoot-impl-boards.mjs` 打的是对照台：画板是手搭的，绕开了路由表、页面组件、
路由守卫和外壳。于是「组件长得对」会被误读成「用户打开那一屏长得对」——
2026-08-26 用户实测反馈「和设计稿完全不同」，而对照台那一轮的分数是 99/100。

差在两处，两处都是**删掉不会红**的接线（`predicate-and-wiring-discipline` 形状 2）：
路由漏了 `placement: 'fullscreen'`，整屏被套进平台顶栏与底部 TabBar；
页面一个回调都没往下传，一键整理／逐句校对／词典／改说话人整块静默消失。
对照台两样都自己补上了，所以它永远看不见这两个洞。

**结论：判分以 `shoot-real-app.mjs` 的图为准**，对照台只用来快速迭代单个组件。

## 稿面画的多半是「做过一个动作之后」

搜索框里已经输了词、某张整理卡正在跑、问题已经问完并出了答案——这些都是**状态**，
不驱到那一步就截图，判官看到的是空搜索框、四张「点击生成」、一张空输入卡，
于是把取证没走到记成实现缺失（第一轮 B4 因此判 39，补驱之后同一份代码 88）。

所以 `shoot-real-app.mjs` 会按真人的操作驱一遍：输入「导入」、点发送并**等答案流完**、
点一张整理卡并等轮询转起来、点波形四成处再按播放。只有网络是桩，点击是真的。

驱不到的状态要**明说驱不到**，在判分请求里单列成「未取证」，不能与「缺失」混记——
也不能默认它成立（`closed-loop-acceptance`：不会红的证据比没有证据更糟）。

## 采集屏要真的录一段

录音那六屏（`v2-R1/R2/R3`、`cap-A1/A2/A3`）没有一屏是「打开就长这样」的：
波形要录几秒才有形状、字节数要等分片上传、实时原文要等服务端推句子、
暂停态要点一下。所以取证要满足三件事：

1. 浏览器带 `--use-fake-device-for-media-stream` 启动 + context 授予 `microphone`。
   少了假设备就停在「正在请求麦克风权限」，要判的那几块一块都取不到。
2. 实时转写走 WebSocket，HTTP 桩够不着它，用 `page.routeWebSocket` 当服务端：
   场景给一串句子就逐句推（正常态），给 `false` 就**连上再断开**（降级态）。
   注意 `ws.close({code: 1006})` 会被拒——1006 是保留码，发不出去，socket 反而一直开着，
   页面永远显示「正常」。用 1011。
3. 从知识库右下角的新增入口点进去，走用户的真实路径，不给面板开测试后门。

## 两条已经踩过的坑

- **编号必须取设计稿自己的代号**（`R4`/`P3`/`S5`），不能用位置序号。
  抓取判据一变，序号整体位移，配对会静默错位——已经因此把失败卡拿去和自动重试比了一轮。
- **取证前要等跟随动画结束再复位滚动**。组件挂载时会把当前句平滑滚到中心，
  过早复位会被动画后续帧覆盖，截出来的是滚过之后的半屏。
