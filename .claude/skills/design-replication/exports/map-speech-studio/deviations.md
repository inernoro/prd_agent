# 语音创作台设计复刻偏差

设计来源：https://www.figma.com/design/wW9cn5adbZqXbNWDj4Dl5V?node-id=2-184 。原生设计上下文覆盖深色创作台2:184、浅色创作台2:417、历史与详情2:650；三张画板均按1440×960比对。尺寸、档位与来源指纹见相邻design-spec.json。

| 画板 | 差异 | 处置 | 原因或结果 |
|---|---|---|---|
| 全部 | 字体与全局窄导航 | 保留 | 按用户要求沿用MAP现有字体栈和全局导航，不复制样例头像或重建应用外壳 |
| 全部 | 工具栏多出返回与刷新 | 保留 | 继续提供返回智能体接入台及刷新当前语音数据的既有操作，移除原高大MCP页头与统计 |
| 创作两色 | 结果卡被额外帮助行推低 | 改掉 | 有效输入不再占用重复帮助行；输入错误仍持续显示；结果卡回到设计位置及166px档位 |
| 创作两色 | 原生拖拽角标与滑杆轮廓 | 改掉 | 文本框保持可滚动，取消拖拽角；语速和播放使用4px轨道、12px滑块，保留键盘操作 |
| 创作两色 | 能力选择器与预设选择 | 保留 | 必须支持不同环境、多上游和不可用旧配置；桌面预设在左栏选择，手机保留选择器，避免重复堆叠 |
| 创作两色 | 右栏说明被挤出首屏 | 改掉 | 收紧间距，保留上游选择、保存预设、范围与单次/每日/并发限制，底部说明完整可见 |
| 浅色 | 首轮截图按钮文字偏淡 | 改掉 | 原因是主题过渡尚未结束时取证；等待稳定后重新截图并核对计算色，无额外颜色覆盖 |
| 历史 | 列表卡高度与详情分隔 | 改掉 | 列表卡恢复170px档位，拉开原文与声音元信息分组 |
| 全部 | 样例标题、原文、音色与数量 | 保留 | 全部绑定后端实际数据；设计样例仅用于浏览器fixture，不写入产品或业务配置 |
| 创作两色 | 预计时长、声音风格描述 | 保留 | 现有能力合同无估算和风格字段，不编造预计秒数、性格描述或更多音色/情绪 |
| 历史 | 未加载文件的列表时长与文件大小 | 保留 | 选中音频在用户点击后读取真实媒体元数据和Blob大小，不为补齐样例数字全量下载私有音频 |
| 历史 | 配置版本与再次使用配置 | 保留 | 保留既有可追溯性及复用草稿操作；点击复用不自动生成，未知结果不可重试 |
| 全部 | 图标与静态进度SVG | 保留 | 图标复用设计注明的同版本Lucide；进度和语速使用真实交互控件，不把静态SVG当动态数据 |
| 全部 | 最近记录与搜索计数 | 保留 | 当前合同返回最近30条；计数、筛选基于已加载记录，不声称账户总历史或资产总数 |

两位独立审查者复看修正后的三屏，均未发现视觉交付阻塞；其主观评分约90%–92%，不代替业务、移动端或真实文件验收。保留项均出于已批准的现有功能合同或真实数据边界，没有删除预设、权限、参数校验、任务进度或资产下载。手机沿用MAP顶栏与底部导航，在自然页面滚动中访问完整编辑、声音设置与音频详情。
