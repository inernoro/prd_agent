# 本地 48 小时自动化提示词

自动化 `stable-smoke-48h` 保留既有本地执行环境、48 小时周期、模型、静默通知偏好和项目。修改真实自动化须使用宿主 automation_update；本文件只是执行合同，不是另一份调度器。

## 提示词正文

执行 prd-agent 核心业务例行巡检，正式环境为主，CDS 只测核心中的核心。先完整读 AGENTS.md、stable-smoke 技能、automation memory 中未关闭缺陷，再读核心功能清单、验收手段、历史池与持久三池状态。F01 至 F31 是业务阅读表，原 caseId 是执行粒度，不从零生成互不相干的报告。

默认 `node scripts/stable-smoke-run.mjs --profile routine --capture-visual`。工具代码与业务部署版本分别记录：从配置的已提交工具 ref 执行，验收当前实际线上功能，不要求发布工具分支或指定业务版本。CDS 现存目标分支由项目级清单精确解析，入口只取 preview-url 权威结果；正式固定 https://map.ebcone.net。禁止把 CDS 称为测试环境，禁止 GitHub Actions 调度。

正式 CORE-001 只读基线优先且独立；CDS 默认 F01、F05、F08、F17、F18，以及有来源的定向复验。CDS 核心功能、清理与对应视觉证据通过后解锁正式完整安全矩阵。P0、污染或清理失败仍熔断正式写入；一般非核心 CDS 缺陷不自动扩大为全量。full 是专项。未执行正式生成独立列出，不引用 CDS 成功替代。

安全装载钥匙串和被 git 忽略的兼容凭据，不打印秘密或票据。专用身份、当前 runId 的 stsmk- 资源、限额模型和单一 MAP 用户保持既有授权；禁止真实用户数据、通用管理员、全局通知、Slack。身份、域名、模型、存储、ASR、浏览器缺项记 conditional。失败最多一次确定性重试，通过仍记 flaky。入口打开不等于功能可用。

每轮读取三池，按原编号优先复验；保留长期 31 项，近期窗口为上海 14 个自然日。同轮重试不增事故频次，阻塞不冒充产品故障，未知原因不变事实。实际结果原子保存并回读三池，报告显示同一 F 编号评分表；未完成也回填，不自动关闭原缺陷、不晋升候选方法。回填回读失败算执行链失败。

手机真实触控点击首页“生图”应用按钮，区分同名统计文字，从列表点击本轮项目，不 goto 深层路径。默认模型、JPEG、支持尺寸和进度按模型实际契约验收。WEB-001 至 WEB-007 和三条文件夹 REG 保持正式安全矩阵覆盖，grep 必须精确选中。

临时草稿不是交付。按 create-visual-test-to-kb 归档 CDS 不可变报告，verify-open 检查标题、正文、图片、锚点与可见真实点击；失败不回退本地路径。老板决策卡、缺陷诊断、截图账本、执行明细、恢复顺序、量化关闭条件交独立业务视角复读，低于 80 分继续改版。pass 只归档；conditional/fail 只用 stable-smoke-notify 向固定目标 inernoro 发已验真同 runId 报告。配置维护不是巡检的自动权限。

最终给简洁结论、问题表、线上证据、自然语言修复交接、下一步与四列验收结果表：标题、导航、线上图片或对应证据、pass/fail。缺实际路径或验真证据标 fail。保留原 defectId、修复 ref、caseId、未关闭问题、验收债务变化和下一轮起点。
