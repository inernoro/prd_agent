# 稳定冒烟测试矩阵

> 本文件是 `/稳测` 的必跑范围。caseId 稳定，新增用例只追加，不复用旧编号。

## 环境级别

| 级别 | CDS 环境 | 正式环境 |
|---|---|---|
| 可用性 | 首页、登录、核心 API、静态资源、SSE | 同左 |
| 权限 | 管理员、普通成员、无权限用户 | 专用合成管理员和普通成员 |
| 写入 | 完整创建、更新、取消、重试、删除 | 专用 `stsmk-` 资源的最小写入和删除 |
| 故障 | 断网、超时、损坏输入、空输入、重复提交、依赖失败 | 只验证自然失败与用户文案，不主动破坏依赖 |
| 视觉 | 桌面、真实触控移动端、关键进度与结果截图 | 桌面关键结果；移动端关键入口轮换但每轮至少一条 |
| 清理 | 全部删除并回读 | 全部删除或回收到固定合成资源池 |

## 09 共性质量维度

每个模块都必须检查：

- 冷启动、刷新、返回、重复点击、并发两次和幂等。
- 桌面与真实触控移动端入口、操作、结果和滚动归属。
- 进度持续变化、超时、取消、重试和后台恢复。
- 成功产物的内容、MIME、大小、时长、尺寸和可下载性。
- 用户可读错误、管理员 requestId、脱敏日志和无敏感信息泄漏。
- 正式与CDS 环境的功能开关、模型能力、文案和版本差异。
- 合成账号、资源前缀、成本上限、自动清理和残留回读。
