# CDS 骨架自检

## 触发与模式

| 触发 | 执行 | 交付 |
|---|---|---|
| 骨架扫描 | 冻结范围，采集两段等待与加载完成态，按实际组件测量布局。源码保持只读。 | 每条路由的双端对比、偏差、未覆盖场景和阻塞 |
| 骨架更新 | 复现偏差，修源码，使用同样条件复拍，跑对应回归。可接收前一次扫描的报告。 | 候选改动、复拍证据、测试结果和仍待验证的范围 |

自然语言、斜杠前缀和自动化提示共用这两个入口。明确要求更新或同时要求扫描和更新时，先取证再修复。原有 `$cds-skeleton-review` 调用默认执行更新。日期、Git 范围、指定路由和全量检查均可直接给出。省略时检查 `origin/main` 在 `Asia/Shanghai` 上一完整自然日的净改动。范围确认无影响时直接汇报基础和目标 SHA，跳过构建和截图。

## 适用场景

- 自动化检查当日改过的 CDS 页面，修正候选代码并汇报。
- 功能分支交付前复验路由、加载骨架或手机布局。
- 指定某条路由重新比对骨架、真实组件和左侧菜单。
- 共享导航、主题或骨架样式改动后复查下游页面。

## 执行清单

- [ ] **确定范围。** 从仓库根目录阅读 `AGENTS.md`、`cds/CLAUDE.md` 与实际变更对应的专项规则。每日任务刷新配置分支的远端引用，保留现有工作区。运行范围脚本，记录基础和目标 SHA，登记候选路由、兼容入口及影响面。日期范围采用第一父提交链上两端快照的净改动。宽泛的共享或未登记文件由人工阅读差异补齐路由，不能以登记表为空推断无影响。
- [ ] **设计用例。** 依次读取同仓库的 `acceptance-test-design`、`acceptance-scenario-orchestrator` 和 `create-visual-test-to-kb`。先查左侧菜单和直达页面，再查二级页、查询视图和其他受影响入口。加上能暴露差异的账号角色、数据状态、断点或返回路径。有可用子智能体且任务允许并行时，按路由分组，统一使用冻结构建和截图条件。公共壳或共享骨架由一个负责人整合。
- [ ] **复现差异。** 打开实际页面，分别采集代码块等待、数据等待和加载完成态。浏览器本地延迟只用于观察等待，可用仓库合成响应或受控预览。每组保持路由、角色、查询参数、主题、滚动位置与视口一致。记录截图、DOM 锚点及受影响组件。优先查菜单高亮与可用性，再比对标题、工具栏、目录、筛选、分栏、卡片、表格、画布和响应式排列。
- [ ] **更新骨架（更新模式）。** 先核对扫描报告的目标 SHA 和场景，基线变化时在当前目标重现。只修已复现的布局差异，在独立工作区或指定分支复用真实页面的容器、公共布局和断点。代码和数据等待尽量使用同一骨架。对初次请求无法知道的权限、分组、条数和服务类型，以可预知区域为准。保留权限检查、重试、慢加载反馈和减少动效行为。
- [ ] **核对证据与复拍。** 桌面 `1920×1080`，手机独立触控上下文 `390×844`。左右拼图左侧骨架、右侧真实组件。记录代码等待到数据等待的连续性，以及骨架到真实内容的关键区域偏移。更新模式用同路由、同数据复拍，并跑前端类型检查、构建、加载覆盖守卫和对应的浏览器回归。
- [ ] **报告。** 按仓库验收流程归档，以 `verify-open.mjs` 确认正文、截图和内部链接可打开。汇报每条路由的状态、修复内容、证据、遇到的问题、阻塞和关闭条件。线上预览或测试账号不可用时保留未验证范围。本地合成数据只支持候选版界面结论。无受影响页面时汇报两个 SHA 和核查结果。

## 调用

```text
骨架扫描
骨架扫描 /project-list
骨架扫描 --base HEAD~1 --head HEAD
骨架更新 /project-list
骨架更新 --date 2026-11-20
$cds-skeleton-review                         # 上一完整自然日
```

使用 [范围、截图与自动化接入](reference/runbook.md) 的命令执行。自动化只传入范围、授权的修复交付位置和报告归属，流程以本技能为准。缺少交付分支时，保留工作区改动或可应用的补丁。提交、推送、合并和上线沿用项目已有授权。

## 结果格式

```markdown
### 阶段一 · 范围与基线
- [x] 日期、来源分支、基础及目标 SHA
### 阶段二 · 扫描、更新与复拍
- [x] 已完成的扫描或修复，附双端截图和偏差
- [ ] 未验证的页面和原因
### 阶段三 · 报告
- [x] 报告链接和打开校验

| 页面 | 桌面 | 手机 | 修复与验证状态 | 证据或阻塞 |
|---|---|---|---|---|
```

## 示例

输入「骨架扫描 /project-list」时，在手机触控视口延迟页面代码，确认菜单入口是否消失，并检查加载前后抽屉可达性和当前项目列表高亮。输入「骨架更新 /project-list」时，在确认差异后复用公共顶栏并用同一用例复拍。报告记录首次请求前无从判定的暂停分组和服务类型。如果同版本线上预览尚未生成，将线上验证列为阻塞。
