# CDS 测试入口

> **版本**：v0.1.0 | **状态**：已落地 | **触发**：`/cds-test`、「领取 / 执行 CDS 上的测试或验收」

这个入口不单独实现任何逻辑，它是 `cds` 技能的一个入口。授权和命令在 `cds` 技能里，浏览器取证和报告用 `create-visual-test-to-kb`。

1. 读 `../cds/SKILL.md` 的「结构化验收任务」和「设计稿件与框架」两节，再按 [测试闭环](../cds/reference/test-loop.md) 执行。
2. 用户点名了任务、稿件或模块就直接领取；没点名就列出待测清单，问一次。
3. 结果只记实测；前置条件不满足的项记为未执行，并写明补跑入口。发现的设计问题写成实施反馈，代码缺陷交给对应的修复流程。
4. 收尾最多五行：测了什么、按哪一版测、通过 / 失败 / 未执行各多少、CDS 链接、需要人签收的事。
