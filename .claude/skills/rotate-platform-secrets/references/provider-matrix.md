# 凭据轮换矩阵

| 类型 | 最小权限 | 新密钥验证 | 撤销前门禁 |
|---|---|---|---|
| 代码托管读取令牌 | 限定仓库、只读内容、短有效期 | 读取指定路径并确认响应内容 | 所有部署与变更日志消费者已切换 |
| OAuth 客户端密钥 | 仅目标应用 | 完成一次真实授权回调和会话建立 | 新旧密钥并存且新密钥回调成功 |
| 对象存储访问密钥 | 限定桶与对象动作，主机侧不授删除 | 上传、回读、大小与 checksum 一致 | 保留锁或服务端策略已生效 |
| 数据库账号 | 限定数据库与所需读写动作 | 新账号连接、读写、备份和恢复 | 已验证恢复副本，全部消费者已切换 |
| 会话或 JWT 签名密钥 | 仅对应服务 | 新登录、刷新、注销和权限校验 | 已通知登录态失效窗口 |
| Webhook 签名密钥 | 限定目标 webhook | 真请求签名验证与重放拒绝 | 发送方和接收方均已切换 |
| CDS 控制密钥 | 项目级优先，创建项目等高权限单独保存 | 读取项目、部署目标项目、拒绝越权项目 | 旧 key 使用日志归零 |

每次执行把本表扩成实例清单，但不得填入密钥值。指纹最多保留提供方展示的前后少量字符。
