# CDS 设计入口

> **版本**：v0.1.0 | **状态**：已落地 | **触发**：`/cds-design`、「维护 / 更新 / 修复某模块的设计」

这个入口不单独实现任何逻辑，它是 `cds` 技能的一个入口。授权、命令和门禁程序都在 `cds` 技能里。

1. 读 `../cds/SKILL.md` 的「设计稿件与框架」一节，再按 [设计闭环](../cds/reference/design-loop.md) 执行。
2. 用户的话就是本次需求：模块名用来匹配稿件，其余内容是修改诉求。只有匹配到多份稿件、或取舍需要用户拍板时才问，最多问一次。
3. 门禁和版本号由 `../cds/scripts/design/release.mjs` 判定。被驳回就按规则编号修改，不绕过。
4. 收尾最多五行：稿件编号和版本、改了什么、净变化、门禁结果、需要人在 CDS 里做的事。
