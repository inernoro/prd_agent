# 独立目标提示词契约

用于“发”阶段。每个任务是一段完整提示词，填入本轮已核实事实；下面是写作骨架，不能把未替换占位符交给用户。

## 必须携带的内容

1. **结果**：谁的什么问题消失，能多做什么；不要把“调查/重构/增加测试”独立当目标。
2. **证据**：原债务定位、复核身份与仍成立的依据；成功条件、具体断言和证据产物。性能任务必须交代基线、工作负载、环境、对比口径及正确性保护；没有数据先测，不编阈值。
3. **边界**：可改范围、保留的不变量、不做的事项、已知依赖和权限终点。云环境可访问的仓库相对路径/链接，禁止只留个人路径或“前文”。
4. **迭代**：先复核现状，若问题仍在则实施，每轮依据实测选择下一步，完成代表性回归与实际行为验收。旧债务已失效时停止无意义实现，核验后只回写处置。
5. **阻塞**：正常等待不是结束理由；真正缺输入、安全/授权/预算边界触达时报告证据和解锁条件，推进独立事项，不伪造成功。
6. **回收**：复核原关闭条件后更新同一债务条目，保留处置依据与残余，完成仓库文档校验，交付任务、代码/PR、证据、预览与账目变化的回执。

## 一段骨架

目标：让【使用者】在【场景】达到【可观察终态】，解决【债务文档及条目】记录的【当前问题】。本轮依据为【复核日期、SHA/环境和事实】，前置条件为【具体解锁结果或无】，与【任务】可以【有依据的并行/先后关系】。先读取仓库及模块规则，核实问题在当前版本仍存在并确定可失败的验收断言；已解决、过期或被落地方案覆盖时，核验原关闭条件并回写依据，不重复实施。问题仍在则完成实现、必要测试和集成验收，不停在调查、方案或构建成功。成功标准：【结果与具体断言】，证据为【测试/基准/真实行为/最终产物及对应版本环境】，必须保持【不变量】，本次范围【范围及不做事项】，权限终点【按用户实际授权写明】。涉及 UI 时，从仓库权威工具查询当前分支真实预览入口，亲自走通业务路径和适用主题/兼容/失败恢复场景，给我实际可用的功能深链；403、不可登录或未部署保持未验收，不猜地址，纯规则文档说明不适用。每轮根据验证结果修正并继续，正常等待和可自行解决的失败不结束任务；真实阻塞时写清尝试、证据、最小所需输入与续接动作，继续独立事项，遵守用户暂停/取消。交付前独立核对原关闭条件和最终产物，重读最新债务文档并仅合并本条变化，记录已解决/部分解决/待核实或过期替代的依据、证据身份与剩余边界，按仓库规则同步索引及检查，安全清理本任务临时资源并保留共享资源；交付改动/任务或 PR 链接（仅实际产生时）、验证结果、预览及债务处置回执，未验证不得写完成。

不要机械保留不适用条款。纯 API 写实际端点/集成断言；纯文档写文档行为与合同检查，说明无需页面预览。若实现权限尚未给定，采用仓库默认开发交付边界，不替用户授权合并、生产发布、数据删除或付费。只让用户决定确实影响目标的未知，不把能自行探查的细节交还用户。

## 返回结果时怎么收

让执行者提供原条目定位、执行任务/PR、最终 SHA、环境/运行版本、原断言的实测结果、证据链接、剩余项和台账变更。没有权限写共享台账时返回精确补丁供有权限者核验应用；这时只能称“待回写”。这份回执不是可信结论，收阶段仍须独立读取证据。
