# 陌生页面引导性原则

**一句话**：用户进入陌生页面 3 秒内要知道这是什么、下一步点哪；空状态说明事实与当前角色可行的下一步，不许用无效操作制造引导。
**什么时候撞上**：新建页面，或处理页面的空状态、首次使用、异常态。

> 用户进入一个全新页面时，必须在 3 秒内知道「这是什么」和「下一步做什么」。

## 引导的边界

先用熟悉的对象名称、稳定布局、合理默认值和清楚的主操作建立预期。说明、插图、脉冲、高亮和教程按真实理解缺口使用，不因本规则机械叠加。普通列表无需同时具备标题、副标题、徽章和说明；只读或无创建权限的空态给真实边界与可行下一步，不展示不可执行的主操作。安全说明和必要状态不为紧凑而删除。

## 强制规则

1. **空状态不能空**：列表为空时禁止只显示"暂无数据"。明确无数据的含义及当前角色可行的下一步；有创建权限且符合任务时提供主操作，不强制插图或额外容器
2. **首次进入有引导**：AI 原生页面（涌现、工作流、Agent 等非传统 CRUD 页面）首次进入时，需让用户知道用途和起点；先依靠名称与结构，确有理解缺口时再补简短引导
3. **操作有反馈路标**：每完成一步操作后，结果与可行的下一步应清楚；不强制增加提示、高亮或动画
4. **形势感知**：页面当前状态（空/少量/正常/异常）必须有对应的视觉表达，用户一眼就能判断"现在是什么情况"

## 引导层级

| 层级 | 触发条件 | 表现形式 | 示例 |
|------|---------|---------|------|
| **L1 空状态引导** | 列表为空且原因明确 | 简短事实 + 可行下一步；有权限时提供主操作 | "还没有涌现树，点击开始探索"；只读用户说明权限边界 |
| **L2 首次使用引导** | 用户从未使用过此功能 | 步骤卡片 / 动画演示 / 示例数据 | "涌现探索器分三步：种下种子 → 探索 → 涌现" |
| **L3 操作提示** | 用户完成某步但不知道下一步 | 高亮提示 / 脉冲动画 / Toast | 节点上的「探索」按钮脉冲提示 |
| **L4 上下文帮助** | 用户停留过久未操作 | 悬浮提示 / 侧边帮助面板 | "试试点击节点上的探索按钮" |

## 设计清单

新建页面时逐条检查：

- [ ] 空状态说明事实及当前角色可行的下一步，没有假CTA
- [ ] 名称和内容已让用户理解用途；仍有理解缺口时才补充说明
- [ ] 用户知道第一步该做什么（主操作按钮醒目）
- [ ] 结果与下一步清楚，不需靠额外解释猜测
- [ ] 异常状态有明确提示（加载失败、权限不足、数据为空）
- [ ] 陌生交互确有理解缺口时提供按需帮助，不把教程常驻首屏

## 反面案例

| 错误做法 | 正确做法 |
|---------|---------|
| 空列表只写"暂无数据" | 说明为空的事实和当前角色可行的下一步；有权限时提供创建入口 |
| React Flow 画布只有一个孤零零的种子节点 | 种子节点上有脉冲动画的「探索」按钮 + 底部提示"点击探索开始生长" |
| 涌现按钮没有解释 | Tooltip 说明"AI 将组合现有节点，发现新的可能性" |
| 新功能页面无任何说明 | 页面顶部一句话说明 + 可折叠的详细引导 |

## 与其他原则的关系

```
用户进入页面 → 「引导性原则」告诉他做什么
         ↓
用户开始输入 → 「零摩擦原则」让他不发呆
         ↓
用户等待 AI → 「2 秒原则」让他不焦虑
```

三个原则覆盖用户操作的完整生命周期：**认知 → 行动 → 等待**。
