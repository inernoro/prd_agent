# CDS 页面切换动效规范

**一句话**：CDS 控制台页面切换默认采用监控总览中已经认可的渐入渐出与连续缩放，复用公共实现，保持原有字体、配色和布局。
**什么时候撞上**：新增或调整 CDS 控制台页面、项目进入分支列表、分支进入详情、菜单进入设置，以及同类页面的进入与返回。

2026-11-11 用户明确要求将此效果沉淀为长期页面规范。

## 交互约定

1. **进入有来源，返回认得位置**：有可用的来源卡片或导航元素时，从该位置连续进入目标内容；返回恢复原滚动、焦点及来源位置。没有可靠来源时使用统一淡出、淡入。
2. **平稳连续**：不添加上下起伏、弹簧回弹或额外位移，不叠加另一套页面入场动画。导航栏保持稳定，由内容区域承接过渡。
3. **镜头只跟随主动导航**：点击进入、返回和主动定位可以触发动效；轮询、状态更新、数据刷新和新增服务不得自动缩放或打乱画布位置。
4. **导航功能优先**：动画不得改变原路由、权限、历史记录或参数；`state`、`replace`、相对路径及滚动语义必须保留。Ctrl/Cmd 点击、新窗口、下载、外链及同页锚点继续保持原生行为。
5. **减少动效与降级可用**：尊重系统 `prefers-reduced-motion` 及 CDS 的减少动效设置；减少动效或浏览器不支持时直接完成导航，不能阻塞、白屏或丢失操作。主题切换与页面过渡互斥。

## 复用入口

| 用途 | 现有实现 | 接入要求 |
|---|---|---|
| 页面链接 | [`MotionLink`](../../cds/web/src/components/layout/RouteMotion.tsx) | 新增控制台页面链接优先使用；保留原链接属性与事件处理 |
| 程序式导航 | [`useSurfaceNavigate`](../../cds/web/src/components/layout/RouteMotion.tsx) | 新增点击跳转、快捷操作等优先使用共享 hook |
| 页面壳与返回恢复 | 同文件的 `RouteMotion`、`RouteMotionCommit` | 沿用页面壳的挂载，不在每个页面重复挂载；实际页面提交后完成过渡与位置恢复 |
| 来源与镜头 | [`surfaceMotion.ts`](../../cds/web/src/lib/surfaceMotion.ts) | 通过 `runSurfaceMotion`、`surfaceCamera` 和共享偏好判断复用 |
| 公共过渡样式 | [`index.css`](../../cds/web/src/index.css) | 复用 `cds-content`、`cds-detail` 快照层及既有主题隔离规则 |
| 监控内部层级 | [`MonitorWorkspace.tsx`](../../cds/web/src/pages/status/MonitorWorkspace.tsx) | 保留全局、分类、服务的来源关系，不再外包一层重复的路由动效 |

页面切换优先使用上述导航入口；组件内部层级切换确有需要时才使用底层镜头函数。不要为每个页面复制一套定时器、动画参数或返回位置缓存。

### 当前节奏

参数的唯一权威是 `surfaceMotion.ts` 的 `SURFACE_MOTION`，下表用于说明现行效果，调用方应读取共享常量：

| 参数 | 当前值 |
|---|---|
| 进入 | 520 ms |
| 返回 | 460 ms |
| 无来源时淡入淡出 | 160 ms |
| 缓动 | `cubic-bezier(.22,.8,.24,1)` |
| 最大放大倍数 | 2.2 |

调整节奏应统一修改公共实现并核对相关页面，不能只在某一页另写一组数值。

## 实现边界

- 使用 View Transition 的内容快照完成过渡。不要给真实 `body` 或长期存在的 `.cds-main` 添加持续的 `transform`，避免改变 fixed 抽屉、portal、弹窗的定位参照。
- 页面过渡期间暂停既有 `.cds-page-enter`、`.cds-drawer-anim` 入场，避免双重动画；过渡完成或中断后清理临时状态。
- 快速连续点击、浏览器前进后退和异步页面提交必须由公共协调器处理，不遗留遮罩、不可点击状态或旧动画。
- 页面返回时等待真实内容与布局就绪，再恢复来源和滚动；用户主动滚动或点击后，不继续强拉位置。
- 登录、外站和独立页面是否进入动效，以共享路由判定为准，不在业务页另维护一张路由白名单。
- 动效沿用现有主题与层级，不以引入背景装饰、改字体或换配色作为接入条件。颜色、背景和浮层刻度同时遵守[主题规范](cds-theme-tokens.md)。

## 变更验收

修改动效实现或新增导航接入时，至少核对：

- 进入目标、返回来源、浏览器前进后退；滚动与焦点保持正确。
- 连续点击、慢页面加载、内容刷新和打开详情抽屉，不抖动、不白屏、不偏移。
- Ctrl/Cmd 点击、新窗口、同页锚点等原生链接行为保持。
- 深浅主题、系统减少动效和 CDS 减少动效设置均可正常使用；主题切换不与镜头动画重叠。
- 从实际运行页面录制进入与返回，确认中间过程连续；静态截图只用于布局核对，不能替代动效时序验收。
