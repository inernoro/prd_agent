# CDS Agent 上手助手 · 指南

> **版本**：v1.0 | **日期**：2026-07-29 | **状态**：开发中

## 适用角色

本指南面向产品经理、老板、业务专家和第一次使用 AI 开发工具的成员，预计阅读 3 分钟。

## 快速开始

1. 打开 CDS，点击“接入 Agent”。
2. 进入“上手助手”。
3. AI 开发经验 1 年以内选“小登”，否则选“老登”。
4. 选择自己的角色并增减推荐技能。
5. 保持“接入 CDS”开启。
6. 下载一键脚本并在目标项目目录执行。
7. 复制启动提示词，交给项目里的 Codex、Claude Code 或 Cursor。

## 以后怎么说

产品经理可以直接说：

```text
把首页的价值说明改得更清楚，改完给我一个能打开的地址。
```

也可以只说：

```text
把这个项目上 CDS，给我地址和登录方式。
```

Agent 应自动识别项目、处理版本、部署并返回最终地址。

## 最终应该收到什么

无需登录时应收到预览地址、无需账号说明和已验证路径。需要登录时还应收到临时验收账号、已验证密码、有效期和实际登录路径。

## 安全说明

一键脚本不包含任何 Key。CDS 项目凭据由 CDS CLI 保存到项目自己的 `.cds/credentials.json`，不会写进提示词或提交到 Git。

临时验收账号只能在私密对话中交付。生产用户密码、海鲜市场 Key 和 CDS Key 不得写入项目文档、PR 或公开日志。

## 遇到问题怎么办

技能清单打不开时稍后重试，或者使用“快速初始化”。CDS 要求批准时只需在页面批准当前项目申请。没有预览地址说明部署尚未成功，Agent 必须继续诊断或明确阻塞，不能自己猜地址。
