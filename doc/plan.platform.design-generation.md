## 目标产物

首个可发布版本不是四套独立功能，而是一个内核和四个投射：

1. 网页托管可选择知识、补两句话并生成可保存网页，生成中直接看到页面生长。
2. 知识库当前文档可选择“生成网页”或“生成 HTML PPT”，目标页自动带入来源。
3. HTML PPT 保留成熟的大纲、生成、微调与发布能力，同时记录知识来源与统一任务身份。
4. 已托管网页可继续“帮我修改”，生成草稿、发布新版本、预览历史并回退。

## 范围边界

- OpenDesign 是可替换的设计 Provider，不是 MAP 的任务中心、知识库、版本库或发布系统。
- 隔离容器属于 CDS Remote Agent 基础设施，可以单独项目化；MAP 不管理 Docker 生命周期。
- 首版默认使用 MAP LLM Gateway 执行网页生成与微调，复用现有 HTML PPT 执行链；OpenDesign 主容器只拿随机占位密钥，真实模型票据仅由 CDS 出口代理持有。
- OpenDesign、Codex、Claude 只有在 CDS 中存在真实运行时、健康检查通过且配置启用时才显示为可用。
- 首版不复制外部智能体实现，不宣称未部署的执行器已经接通。
- 首版不重写 HTML PPT 已有成熟链路，只补统一来源、任务与发布回写契约。
- OpenDesign 网页修改首版只支持声明式、自包含单页 HTML；脚本、表单、外链资产和 ZIP 多文件站点在任务创建前拒绝。

## 验收目标

| 编号 | 用户旅程 | 必须发生的结果 | 证据强度 |
|------|----------|----------------|----------|
| AC-001 | 网页托管引用知识生成 | 选择知识并输入短要求后，页面持续生长，完成后成为可再次编辑的托管网页 | 预览环境真人路径 |
| AC-002 | 知识库直达网页 | 当前文档一键进入网页生成，来源已带入且产物记录来源快照 | 预览环境真人路径与数据记录 |
| AC-003 | 知识库直达 HTML PPT | 当前文档一键进入 HTML PPT，来源已带入，可生成并发布到网页托管 | 预览环境真人路径与发布记录 |
| AC-004 | 已托管网页微调 | 修改生成草稿，发布后形成新版本，历史版本可预览并回退 | 预览环境真人路径 |
| AC-005 | 执行器事实展示 | 未部署的 OpenDesign、Codex、Claude 显示不可用原因，不能被选择或假装执行 | 接口与界面双证据 |
| AC-006 | 刷新恢复 | 生成中或完成后刷新，仍能按同一任务恢复阶段、产物和来源 | 集成测试与预览环境 |

## 发布门

- 四个入口使用同一知识引用结构与任务标识，来源删除后仍保留生成时快照；网页微调刷新后可按站点找回未完成任务。
- MAP 进程内模型调用经过 LLM Gateway；外部 Provider 只经 CDS 托管运行时，二者都使用服务器权威 Run、Worker 与可续接事件流。
- 等待超过两秒时，主视觉展示正在生长的网页或幻灯片，而不是静止加载文案。
- 生成产物在隔离预览中运行，不能读取 MAP 的认证存储或私有接口。
- CDS 动态容器全部就绪，公开预览域名完成四条真实路径验收。
- Provider 能力目录必须显示执行归属、隔离要求和真实可用性；会话级资源尚未强制时不得启用 OpenDesign。

## 已知后续

- 首版候选链提供持续阶段和用时变化，尚未把 OpenDesign 工作区中的临时 HTML 作为实时画面传回；最终原子提交不受影响，后续可增加只读临时快照。
- 会话并发配额当前由单个 CDS 进程原子管理；多副本部署前必须迁移到共享配额事实源。
- Workspace 输入包包含知识快照并作为运行审计证据随 Run 保留；首版尚未建立独立保留期、引用计数和自动清理策略。进入生产前必须与知识快照、站点删除和合规保留规则一起确定，不能由对象存储自行永久增长。
- 本次升级前已创建且没有冻结 CDS 连接标识的 OpenDesign 在途任务会安全失败并要求重发；部署窗口需先排空旧任务，不能承诺跨版本续跑。
- 受限知识引用当前保存来源快照并把工作区相对链接降为不可导航标记；发布闸门已校验来源外数值和敏感事实，面向读者的引用查看器、claim 级映射和同值指标语义比对留待后续。
- 多知识条目组合、跨库检索和向量召回不阻塞首版，首版以用户明确选择的知识快照为准。
- 新 CDS 节点不会提前宣称 OpenDesign 可用；它会在后台安装固定衍生镜像，并在 Docker、OpenCode CLI、资源策略和健康探针全部通过后启用。
- 其他外部执行器的授权、资源配额和模板许可证清单在启用前单独验收。
