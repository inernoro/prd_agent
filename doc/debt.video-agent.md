## 当前架构

视频创作支持两条正式路径：

1. 直出模式：提示词或首帧图片经 LLM Gateway 路由到视频模型，异步提交、轮询、下载并保存到资产存储。
2. 分镜模式：文学稿经聊天模型拆分为镜头，用户在制作台逐镜编辑、批量生成、保留历史版本，最后由 ffmpeg 统一画幅和编码并合成为完整 MP4。

火山方舟 Seedance 通过 `volcengine-video` Exchange 转换器适配原生异步任务协议。OpenRouter 兼容协议仍由原视频客户端处理，两者共用 `video-agent.videogen::video-gen` 调用方和模型池治理。视频生成调用已统一切换到 LLMGW 权威路由（HTTP 模式）：发送阶段锁定首次解析出的模型，避免二次解析漂移到其他 Provider；下载在该模式下经网关安全注入密钥后取回成片。

## 验收约束

- 不以 API 返回成功代替视频产物验收。
- 正式闭环必须覆盖提交、轮询、下载、资产保存、分镜合成和公开播放。
- 生产 canary 必须限制视频提交数量，避免重复生成造成真实费用。
- 音频、字幕和模型特有能力未接入前必须在界面明确展示边界，不允许静默假装可用。

## 取消与费用核对边界（2026-10-23）

取消请求停止后续提交，不代表已提交的供应商任务停止生成或计费。与平台撤权合同整合后（2026-11-08），本地任务立即进入 Cancelled 并撤销生成租约；供应商终态、可空费用和核账时间独立记录，不能用本地取消推断供应商停止或免费。历史取消任务缺少核账记录时，不能借新逻辑宣称已核对。

取消后的十分钟查询窗口结束仅回到现有排队态，下一次按独立入队时间公平领取同一个候选并继续核对原作业，不重新提交；历史缺少入队时间的排队任务首轮优先，再入队时写入新时间，不回填历史数据。不增加供应商取消接口、不猜删除地址。此段排队描述适用于尚未被平台撤权的旧核对路径。新取消路径在同一原许可内冻结 owner/run/job/model/offering，以独立、短期、带代次的只读收据身份每轮查询一份并让出其它 worker 路径；绝不恢复原生成租约。此身份仍受原 MaxCalls、MaxRuns、期限、操作者/凭据版本和金额预算约束，不能重新提交、下载或发布。缺少原 Offering/模型、历史已取消且未冻结目标或原许可已失效的记录不自动补授权；保留待核账，不迁移历史数据。现有平台租约保护仍保留，但生成持久化失败与真实崩溃恢复尚需专项实证。

无费模拟测试覆盖已观察到取消时不再下载或发布视频；下载、保存与取消并发时阻止取消后的结果写入任务。若取消恰好落在保存对象与条件写回之间，未被任务引用的对象仍可能残留；本次不在缺少全局引用证明时删除内容寻址对象。

严格内存 mock、本机 HTTP 与临时界面 AST 专项仅提供本地工程证据；临时专项不在默认 CI，不能代替永久回归或准确公开版本的真实用户路径与最终账单验收。原视频真实费用已超过授权上限，未获新预算前不再触发视频、上游查询或取消，未验证的真实核账和公开界面必须保留未通过状态。

### 原有限清单 U40：素材下载安全与后续责任边界

视频下载上限和格式校验按旧来源单独承接，保留当前安全出站地址验证；本地合成 HTTP 响应与存储替身只能证明消费链的拒收和格式传递。短视频任务的取消、受控清理及当前 TaskExecution 处理归属仍需另行收口，不能以下载子包工程通过或旧广包已关闭声明整项完成。公网真实素材/转写验收未完成，不创建视频或转写任务、不操作已有物理对象。

本下载子包的上游响应证据经有界脱敏进入既有管理员API请求日志，可按记录编号及工作流执行关联查询；用户错误不携带上游正文。审计写入失败必须显式拒绝素材写入。此边界仍需准确最终版本真实验收，不代表取消、清理或处理归属已闭环。

管理员审计保留有界脱敏的失败阶段、格式拒收原因与异常链，区分未知签名、格式错配和连接时私网拦截；普通用户仍只看到恢复动作和记录编号。
