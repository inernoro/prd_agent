# CDS 结构化产品功能验收

> **版本**：v1.0 | **日期**：2026-10-02 | **状态**：实施中，未宣称线上验收通过

**一句话**：重要产品功能先成为可复用清单，智能体领取每轮任务，逐项留下结果，再形成报告与历史矩阵。
**谁该读**：产品负责人、验收执行者、修复智能体与 CDS 维护者。
**读完能做什么**：制定清单、判断结果可信度，并明确每轮监控和发布门禁的边界。

## 业务目标与范围

每 48 小时监测的是正式环境已经存在的重要产品功能，不是某个待发布分支。
清单以“用户能完成什么”为行，而不是以截图、接口存活或部署状态为行。
CDS 只安排核心中的核心子集；正式环境任务独立创建，不以 CDS 完整矩阵、指定分支或特定版本为前置。
部署版本可以观测和记录，但缺少待发布版本不能阻止稳定性巡检。

本期实现清单、任务、结果、报告关联与矩阵；复用既有验收中心、项目身份、存储及 CLI。
不增加调度器，不替换现有 48 小时自动化，不自动发布，不扩大真实业务数据写入授权。
领取任务只授权回填验收记录，不能自动授予执行者操作目标产品的权限。

## 四层数据与责任

| 层次 | 固定内容 | 每轮变化 | 负责人 |
|---|---|---|---|
| 测试清单 | caseId、模块、功能、入口、步骤、断言、证据要求、清理要求、环境策略 | 发布新版本，旧版本保留 | 产品与验收负责人 |
| 执行任务 | 清单版本及完整快照、环境、选中用例 | 创建独立任务、领取与执行状态 | 执行智能体 |
| 逐项结果 | 原 caseId 和断言身份 | 实际结果、证据、清理回读、重试历史 | 执行智能体 |
| 验收报告与矩阵 | 任务身份与已归档正文 | 新一轮形成新列，不覆盖旧列 | 平台汇总，负责人复读 |

清单每行包含功能标题、模块、核心级别、环境、业务面包屑、入口路径、前置条件、测试输入、操作步骤、预期结果、可判定断言、证据要求、清理方法和负责人。
新增模板版本不改变已经创建的任务；矩阵保留历史用例，不能因模板删行掩盖旧失败。

## 执行闭环

产品负责人发布清单版本 → 创建本轮任务 → 一个执行者领取 → 按真实业务路径执行 → 逐项回填 → 结束任务 → 从结构化结果生成报告 → 在线归档并绑定 → 线上打开验真 → 查看历史矩阵。

任务状态为待领取、执行中、已结束或已取消。执行者使用有期限的领取票据，持续续租；过期后可以重新领取，但旧执行者不得写入新一轮操作。
票据不进入列表、结果文件、报告或聊天；项目级身份不能读写其他项目。

用例结果区分通过、失败、阻塞、未执行。阻塞与未执行不能算通过。
通过要求所有断言通过、实际结果非空、所要求的线上证据齐全，以及需要清理时清理回读通过。
线上 URL 的格式校验不能证明图片可访问或页面可用，执行者仍须真实打开与取证。
首次失败最多确定性重试一次；重试成功保留首次失败，并标为不稳定，不算稳定通过。
同一提交身份重复发送不得重复计数，改内容复用身份必须拒绝。

## 报告与质量门禁

报告由本轮冻结清单和结果生成，不能用一份无关联的自由文本报告代替回填。
报告归档复用现有验收中心，按项目和文件夹分类；任务身份提供幂等，重试归档不生成重复报告。
归档正文、结论与任务结果必须一致，且正文进入持久化对象存储后才可绑定。
绑定后的任务报告不可改正文、改结论或删除；可以移动分类，新复测必须创建新任务。

“业务汇总通过”与“交付完成”是两个状态。报告绑定后仍显示线上打开待验证；没有浏览器验真，不得称验收报告完成。
本期不提供由客户端自行声称验证通过的按钮，也不自动把业务通过接成发布批准。
未来发布门禁必须另行明确门禁范围、当前执行证据和审批策略，不能拿历史绿色替代当前验证。

## 需求质量与复用判断

| 检查 | 结论 |
|---|---|
| 模糊、不可测试、遗漏前置、隐含假设 | 已收敛为固定字段、逐条断言、环境策略、身份与证据要求 |
| 矛盾、不可实现、过度耦合、缺少价值 | 正式环境独立；人工定义产品价值，平台仅汇总结果，不承诺自动修好产品 |
| 现有能力 | 验收报告、项目作用域、对象存储、CLI 已存在，直接复用 |
| 真正缺口 | 版本化清单、可领取任务、结构化逐项结果与历史矩阵 |

价值七维度评分（满分 5）：清晰度 5、完整性 4、可测试性 5、可行性 4、复用性 5、用户价值 5、风险可控性 4；结论为按已批准边界实施，自动调度与自愈留待后续连接。

## 六维风险与措施

| 维度 | 概率 / 影响 | 防护与验收 |
|---|---|---|
| 正确性 | 中 / 高 | 快照、断言身份、后台汇总、失败重试历史必须有红绿测试 |
| 兼容性 | 低 / 中 | 原报告入口保留；普通报告来源不改变去重语义 |
| 性能 | 中 / 中 | 有限用例与证据，状态容量保护，拒绝新增而不删除历史 |
| 安全 | 中 / 高 | 项目隔离、私密租约、过期防写；不授予产品数据操作权限 |
| 运维 | 中 / 高 | 定期回收过期租约、健康状态可读、写失败不返回假成功 |
| 体验 | 中 / 中 | 可视表单、明确未执行原因、矩阵直达用例，双主题与移动端待实测 |

## 验收与交接条件

1. 能发布两个模板版本，旧任务继续使用原快照；核心 CDS 子集与正式环境清单独立选择。
2. 并发领取只能一个成功；租约过期可重领，旧票据提交必须失败；服务重启后结果仍能读到。
3. 缺断言、缺实际结果、缺要求的证据或清理失败不能通过；重试保留失败与不稳定标签。
4. 从任务生成报告，归档重试复用同一记录；伪造正文、跨项目绑定、本地正文绑定均拒绝。
5. 页面能完成清单编辑、任务创建、领取、逐项回填、报告归档；从真实导航进入并验证明暗主题与移动端。
6. 矩阵每列对应一轮，能定位失败项与证据；新增清单版本不抹除旧结果。
7. 编译与自动化测试通过后仍须真实线上路径验收；未经实际执行，不得填产品功能通过。

已知边界和后续关闭动作见 [验收中心债务台账](debt.acceptance-center-cds.md)。
