# MyCDS 外网通行证 · 设计

> **版本**：v0.3 · 2026-10-19 · 内网直连先验收，真实公网节点尚未提供

**一句话**：把本地数据库工具的外网连接收敛为按人、按库、按 IP 和期限审查的临时通行证。
**谁该读**：需要数据库外网访问的使用者、项目负责人和 MyCDS 管理员。
**读完能做什么**：核对申请到撤销的流程、审查和隔离边界，并决定公网入口与首版权限。

## 用户得到什么

在数据库连接页申请通行证，默认选中当前页面访问 IP、只读权限和 30 分钟。复制完整连接信息后点击放行；页面同时显示账号、目标数据库、实际期限和审查结论；连接审计另行显示。复制或申请成功不代表连接成功。

可点击预演见仓库 assets/prototypes/cds-public-pass-preview.html。其地址、账号、密码、IP、审批与倒计时均为演示值，不连接真实后端、不开放端口。真实验收报告另归 MyCDS 验收中心。

## 部件与环境边界

| 部件 | 职责 | 部署位置 | 处理方式 |
|---|---|---|---|
| MyCDS 控制面 | 身份、范围、申请、审查、事件和凭证 | 现有 MyCDS 主机 | 复用能力，增加通行证适配 |
| 专用公网网关 | 接收数据库客户端连接并识别真实来源 | 待指定的 MyCDS 专用公网节点 | 新部署，不能复用其他环境入口 |
| frp | 加密反向通道 | 网关和 MyCDS | 使用成熟实现，不自造协议 |
| 通行证代理 | 白名单、期限和现有连接关闭 | MyCDS 隔离网络 | 复用已有代理，补可信来源处理 |
| 三类数据库 | 数据与受限临时账号 | 各项目内部容器网络 | 逐引擎适配与验证 |
| miduo.org | 另一套环境 | 独立系统 | 不访问、不修改、不部署 |

本期只写申请状态、范围绑定、可信 IP、临时账号、策略适配与用户可理解的失败反馈。隧道、数据库权限、既有登录和审查设施直接复用。

## 流程和数据

申请先绑定项目、分支、资源、目标库、权限、IP、30 分钟期限和申请人。只读申请检查既有项目权限；生产资源或读写申请由管理员审查，批准绑定本申请的具体范围。审计保存成功后才能放行网络，通道就绪后开始期限。

每证独立账号、随机密码和访问通道；凭据仅授权本人查看或复制，加密保存，日志不记录密码。账号只授权目标库，数据库工具连接要求 TLS。浏览器识别的公网 IP 可能与工具经 VPN 的出口不同，页面允许显式核对和重新申请，不静默放宽白名单。CIDR 会归一化为实际网络范围，单项或多项组合覆盖全部 IPv4 均拒绝。

公网路径为客户端、专用网关、加密反向通道、MyCDS 代理和目标数据库。网站保持现有 HTTPS 入口。原数据库端口维持内部访问；转发层须保留真实客户端 IP，不能把所有来源都当作网关 IP 获准。

## 当前内网实现与验收边界

用户确认没有公网节点，允许先在内网验证。当前网关仅绑定 MyCDS 的指定内网地址；本地电脑需能路由到该地址，不把 Cloudflare 网站可访问当成数据库直连可达。未来专用公网节点仍需另行部署和来源 IP 转发适配。

流程为申请、复制连接信息、放行当前白名单。默认使用页面访问来源 IP、30 分钟、只读；页面和数据库工具经不同网络出口时可以明确调整白名单。准备阶段持续保留独占TCP端口，但立即拒绝连接且不转发到数据库；放行只启用同一监听器，不释放重绑。有效期从成功放行开始，复制的账号、端口与CA保持绑定。

三库在网关终止客户端经过 CA 验证的 TLS；MySQL 继续通过 CA 验证的 TLS 连接内部数据库，PostgreSQL 和 MongoDB 连接主机内部环回端口。MySQL 网关检查登录账号与目标库，禁止连接中切换账号；MongoDB 检查 SCRAM 身份与命令目标库，拒绝不受支持的压缩协议和重复 BSON 字段，原实例必须开启身份认证。连接信息包含 CA 证书，客户端必须启用证书验证。MySQL账号管理通过固定回环连接执行CA校验（VERIFY_CA），不要求自动生成的服务端证书包含回环IP；不关闭CA验证。网关证书到期前7天轮换，并校验地址、密钥匹配与有效期；已准备或已放行通行证保留原CA，后续轮换不会改变已复制凭据。每证独立随机密码，加密保存；只有签发本人且仍有资源权限的管理员可以复制。首版只读，无长期授权和读写放行。

PostgreSQL 额外绑定启动报文的库和账号；存在提权执行函数、外部数据表或 PUBLIC 写权限时拒绝签发，不能为了通行证改变原数据库的业务权限。三库临时账号仅授予目标库的读取权限，回收只针对新建临时账号。新建 PostgreSQL 表需要重新申请才能补齐读取权限。

审计记录范围审查、账号准备、凭据复制、网络放行、允许与拒绝的连接、断连和账号回收，不记录密码，也不把网络连接通过称作数据库登录成功。拒绝事件采用令牌限流与按证汇总，审计最多保留三个 1 MiB 文件；这是有界的运行审计，长期留存需管理员另行归档。审计写入失败不允许新连接。通行证账本、凭据和证书不参与构建缓存发现、清理和导入导出。审计残缺记录保留原文并提示管理员，不阻断证件列表与撤销；后续写入保持独立行。到期先关闭入口和现有连接，再回收账号；回收失败单独显示并重试。控制面重启会关闭并撤销旧证，不自动重新放行；原资源身份变化时旧证不能用于新库。原回收目标以加密快照保存，不对外返回；换端口后分别回收原目标与同库同引擎的新目标，原目标不可达时保留待重试，不能把新目标回收成功当成全部完成。并发申请在发现目标前同步预占全局50张上限。

PostgreSQL 临时角色属于整个实例。回收先连接 `postgres`（必要时尝试 `template1` 或仍存在的原库）禁用登录并终止该角色的会话；原库仍存在时清理其授权，原库已删除时继续删除角色。认证或授权清理失败保持重试状态，不冒充成功。

确认回收成功后立即删除账本中的临时口令、管理员回收快照和逐证 CA；终态历史全局最多保留最近 100 条。加载旧账本时同样清理和裁剪，生命周期事件按审计日志的有界留存规则保留。准备、活动和回收失败的记录不裁剪，回收尚未确认或持久化失败时保留加密重试凭据。

本阶段完成条件是正常页面点击闭环、三种本地客户端真实直连、权限反证、到期断连、旧密码不能重新登录和审计回读。内网结果只能证明同网络下的直连实现，不能作为公网穿透或合规认证的证明。

## 失败与恢复

| 情况 | 用户结果 | 系统处理 |
|---|---|---|
| 角色不符或审批拒绝 | 未放行、原因与申请编号 | 不执行写入，不生成可用公网入口 |
| 审计保存失败 | 审计失败，可重试 | 不放行，回收准备中的账号 |
| 网关不可达 | 网关连接失败，期限未开始 | 不伪报连接成功，保留诊断记录 |
| IP、认证、TLS 不匹配 | 对应错误和核对方法 | 拒绝连接，不自动绕过保护 |
| 数据库超时 | 目标库连接超时 | 指向数据库状态，显示失败而非成功 |
| 到期、撤销或主控重启 | 已关闭、旧连接断开 | 独立绝对期限不续期，新连接拒绝 |
| 临时账号回收失败 | 入口关闭，回收待处理 | 先关闭访问，再报警与重试 |

首版审查通行证权限并记录连接事件；完整 SQL 内容审计需要数据库原生审计设施，不能把网络连接日志当作 SQL 审计。

## 角色终点

使用者拿到可用连接和到期时间；项目负责人拿到可核对的范围与结果；管理员拿到申请、批准、连接、撤销及账号回收证据。任一流程停在请求已提交、复制成功或任务已入队，都不算到达终点。

## 验收条件

从真实外网客户端分别连接 MySQL、MongoDB、PostgreSQL，验证允许 IP、禁止 IP、目标库边界、账号权限、审批拒绝、审计故障、到期现有连接关闭与重启不续期。数据库控制页另用隔离空库验证 CRUD、批量、事务、错误中止与主题布局。Agent 命令必须证明审批前未执行、审批后只执行批准内容，不能机器自审自批。

Demo、API 返回成功、容器启动、旧截图、只截进度和容器内访问，均不能替代真实外网或页面验收。

## 范围与默认决策

首版包含当前 IP、30 分钟、专用网关、每证临时账号、范围审查、连接留痕、到期撤销和三库验证。默认只读；读写优先在隔离副本执行，业务库另行明确授权及恢复方式。永久开放、全网白名单、多地域网关和通用逐条 SQL 审批暂不进入首版。

分阶段先交付预演和实测问题，先完成内网三库闭环，再接一个专用公网网关，最后逐引擎扩展。网关主机及费用尚未确定；没有可达公网入口时不得宣称公网连接已完成。

关闭通行证开关、撤销活动凭证并停用专用网关即可退出，不迁移业务数据。触及其他环境、使用业务库做破坏性测试、未确认网关目标、范围超出三模块十五文件或连续三次提交无新行为通过时停止扩展并重新核对。
