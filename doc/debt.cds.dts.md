# CDS DTS 数据传输能力边界 · 债务

> **版本**：v0.3 | **日期**：2026-11-18 | **状态**：开放

**一句话**：按真实验证逐步开放传输能力，默认保留只追加、版本检查和未知结果时的写入保护。
**谁该读**：CDS 运维、DTS 维护者和数据同步验收负责人。
**读完能做什么**：判断哪些数据可进入当前同步范围，以及扩大范围前必须补齐什么证据。

## 开放事项

| 事项 | 影响与暂缓原因 | 当前兜底 | 关闭条件 |
|---|---|---|---|
| 五类服务统一准入 | 五类已接入策略预检与原生传输，Web、MCP、cdscli 已完成隔离传输与对账。主干的真实服务检查已通过，待补正式环境选定任务的准入、停止恢复与对账 | 能力按实际安装的适配器开放；SQL 限 MySQL 8 / PostgreSQL 16，Redis 限 7.4.2 / 8.4.0 同版独立实例，RabbitMQ 限 3.13 同版持久拓扑 | 选定任务在正式环境按实际运行镜像验证权限边界、容量与结构准入、冲突拒绝、停止恢复和目标侧独立对账，并留存适用入口的结果 |
| BSON 与批次容量 | 非文本主键、嵌套结构及大集合尚未完成无损和资源验证 | 文本主键与批准标量字段；一万条、八 MiB 上限，超限阻断 | 无损测试、稳定分批与游标恢复证明，资源上界可核实 |
| 极端中断恢复 | 提交不明、原生历史过期或准备阶段进程中断可能使任务长期处于保护状态 | 只查询原编号，保留写入锁，不按时间自动抢占未知任务 | 真实进程中断、历史过期和原生任务不存在场景均能证明旧写入已终止，再安全恢复 |
| SQL 外部容量与副作用 | 外部 SQL 尚无可信的数据卷容量来源；触发器、外键级联、MySQL 额外唯一键和主键大小写合并可能越过选定范围 | SQL 写目标绑定托管服务实际卷；拒绝触发器、外键关系、歧义唯一键及非二进制 MySQL 主键；不自动变更结构 | 具备可关联实际服务的容量观测与关系映射，并有非破坏迁移及真实恢复证据 |
| 拓扑与缓存扩展 | Redis 跨前缀、集群及新版本序列化，RabbitMQ 临时队列、复杂参数和消息副本未验证 | 固定前缀和已验证版本；Redis 只追加且禁用淘汰，RabbitMQ 目标活动通道阻断；不覆盖现有拓扑 | 分别验证类型、TTL、容量、消息语义、冲突与中断恢复后再扩范围 |
| 账号发现延迟 | 当前每五秒检查缺失账号，尚未接入业务创建事件与稳定 CDC | 页面明确检查周期；每日校准仅针对已批准字段，授权撤销实时走统一身份 | 新建事件可可靠去重、重放和补偿；延迟、断网、撤销与多版本测试通过 |
| 真实交付：生产数据任务启用 | 暂缓，下次启动时复核。正式源、备用目标、账号字段白名单及待同步业务对象尚未选定，生产业务库传输和定时账号资料校准均未开启 | CDS 登录与项目授权实时由主站校验；资料同步只在选定环境对和字段后开启。业务数据只追加，同账号仅对批准字段以正式环境为准，目标专属数据保留 | CDS/DTS 维护者与业务数据负责人确认范围后，实际验证容量、结构和不同验收版本下的准入与阻断，完成首批受控传输和目标单独对账；验证批准字段的每日校准、新账号到达时间与异常补偿，保留目标专属字段并归档证据 |

## 2026-11-18 主备发布验收更新

[统一发布 PR #2052](https://github.com/inernoro/prd_agent/pull/2052) 已合入主干，两端实际运行 `61893b2b62` 并保留备用已有修复。公网已复验备用首次登录、同一普通账号的项目授权与撤销、账号禁用及 MCP、cdscli 凭据吊销，关闭原「真实交付」条目中的身份与发布缺口。正式数据任务按上表保留为开放事项。公网偶发中断见 [CDS 主备台账](./debt.cds.md#2026-11-18-主备统一发布后的待办)及[发布验收报告](https://cds.miduo.org/reports?project=prd-agent&folder=5fa68f9ecf0e4c65a51437c7060bfd73&report=7879c47ca09545b0bf3e4748542c1368)。

## 责任与复核

由 CDS/DTS 维护者按 [实施计划](./plan.cds.dts.md)逐项关闭。正式环境为权威源、已有业务数据默认只追加、账号资料白名单覆盖和版本兼容检查属于业务规则，不得通过关闭保护来核销债务。
