# MAP 信息高效传递 · 分阶段验收计划

> **版本**：v0.2 | **更新日期**：2026-11-20（北京时间） | **状态**：已实跑首轮，修复作者纠正后继续复验

**一句话**：逐步验收从模板到交付再到接收者执行的路径，让作者保住原文和关键判断，让接收者少读、少找、少回问。
**谁该读**：产品负责人、实现者、验收者和接手人。
**读完能做什么**：看到当前做到哪里，按勾选项执行和复查，判断问题影响什么、由谁处理、什么时候可以恢复。

- [x] **B1** 冻结「恰好 200 条」案例的附件、截止冲突、执行人及审核人动作、例外和作者裁定。证据见[演练资料](./guide.knowledge-base.information-delivery.md#同一组演练资料)。
- [x] **B2** 定义正常、失败与恢复的观察点，明确如何从入口、真实产物、已归档版本和来源核验通过。本清单列明断言与主证据。
- [x] **B3** 独立预览首轮部署 `d959e1db2`。已核对作者和只读接收者角色、私有演练库和实际文本、语音模型。通过演练团队授予接收者权限。完成正向验收后移除测试成员复验撤权，保留产物供作者复查。[演练库](https://information-delivery-design-codex-prd-agent.miduo.org/document-store?store=eb7bb5c85c3a46d49fd9f4f4b282eb81)
- [x] **B4** 已记录基线、失败对照和等待阈值。现有网页运行约 1 秒内首次读到队列状态，约 76 秒首次读到预览，最长静止间隔 17.4 秒。基线没有同任务作者补答，待候选版复测。验收时点击后 1 秒内显示正在开始，运行中 45 秒内有进展或可解释的等待状态，180 秒内出现首个实际可读文件，刷新后 15 秒内回到同一任务。模型和网络等待超过阈值时要有清楚的进度或恢复说明。

### 连续性与并发路径

| 路径 | 试法 | 看什么 | 失败条件 |
| --- | --- | --- | --- |
| 正常 | 附件就绪后开始，让真实任务自然完成。 | 开始反馈、流式状态、首个文件、结果入口依次可见，任务标识一致。 | 状态倒退、反复出现整页加载、须手动找结果或产物缺失却显示完成。 |
| 慢速 | 使用可安全重现的慢速输入或测试环境限速。 | 首次反馈和长时间等待有说明，最新已生成文件仍能打开。 | 超过 B4 登记的阈值仍没有反馈、出现虚假进度或重复创建任务。 |
| 失败 | 在测试环境制造可控的依赖报错、文件失败或超时。 | 用户看得见失败位置，资料、补答与可用文件仍可查。 | 错误吞掉、失败显示完成或交付未完成的产物。 |
| 恢复 | 生成和补答期间分别断线、刷新或按页面重试。 | 回到同一任务上下文，待应用纠正和文件可查，重试结果可区分。 | 任务身份跳变、消息或文件丢失、同一操作重复归档。 |
| 并发 | 快速重复点击开始、归档，再从两端对同一任务提交相互冲突的补答。 | 同一次开始只有一个任务，同一目标只有一份交付。冲突显式提示，当前有效裁定可查。 | 重复创建或交付，已确认的裁定被静默覆盖。 |

## 阶段 5 · 真实验收

### 从模板入口走到接收者能执行

- [ ] **E1** 从非正式预览登录。确认入口首屏只展示平台模板，打开完整示例和骨架，再上传 A、引用 B，在统一附件区核对后开始。另一次真实运行验证提示词留空。
- [ ] **E2** 观看同一任务的 SSE 和实际中间文件，核实 OpenDesign 与本地 Codex 执行记录。对缺口补答，主动调整草稿顺序，并对照修订前后文件和最终结果。
- [ ] **E3** 作者从生成页进入结果，打开网页、播放真实生成的音视频并检查教程题。按标题点选 200 条对应章节，核对选中状态、播放位置和实际内容。
- [ ] **E4** 分别归档到网页托管和知识库。从实际交付深链用接收者账号打开网页、播放音视频并做教程题，验证能说清边界、角色和例外，并定位正文、原文和作者裁定。修改资料后复查旧交付。此项验证接收者角色的功能。
- [ ] **E5** 实测有权限、无权限和权限撤回三类账号。接收者的权限应控制可见内容与来源，网页交付不能泄露受限信息。
- [ ] **E6** 按连续性矩阵重跑，包含失败提示、断线恢复、刷新后的任务身份、重复点击和并发。保留页面主证据和对应的脱敏执行记录。
- [ ] **E7** 桌面和手机各用连续的一条任务记录自首屏至归档，核对明暗主题。按适用原稿版本、视口和状态对照实拍，依次呈现开始、生成过渡、补答、文件、结果。没有对应原稿的画面按设计和指南验证，并注明逐图核验仍待补证。

### 证据怎么认

E1–E7 以同一交付候选版本的真实预览为主证据。每条带部署 SHA、可复查入口、角色、任务或产物标识、设备、操作和结果。页面录像或截图证明相关动作，真实执行记录佐证 SSE 和生成链。确定性数据用于可重复回归，真实预览和实际模型运行单独标记。API 成功、构建通过和证据站只提供各自的技术或展示证据。
