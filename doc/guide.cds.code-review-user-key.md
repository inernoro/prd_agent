# 代码审查使用自己的模型 Key · 指南

> **版本**：v1.0 | **日期**：2026-11-09 | **状态**：已落地

**一句话**：审查者可选择自己的模型凭据，并查看经本网关产生的真实 Token 用量。
**谁该读**：提交审查的用户、MCP 使用者和负责启用通道的管理员。
**读完能做什么**：选择凭据、设置保护额度，并正确理解用量、费用与账号余额的区别。

## 用户操作

进入《代码审查报告》发起审查，在“更多选项”把模型额度来源改为“使用自己的 API Key”。选择 OpenAI、Anthropic / Claude、OpenRouter 或 DeepSeek，填写该供应商支持的模型名称、Key 和任务 Token 保护额度。提交前可返回修改，提交后任务固定凭据与模型；失败不会改用平台额度。绑定失败会保留失败任务及脱敏上游证据，需要重新填写 Key 提交，不能当作平台任务重试。

任务的“审查详情”显示本次输入、输出、请求数和此 Key 在当前项目的累计记录。Key 本身不回显、不写入浏览器存储、报告或 MCP 配置。个人账号和项目机器凭据分别归属；同项目其他成员不能继续消费别人的 Key。系统所有者可以查看排障用量，但不能代替凭据所有者重试消费。

保护额度按每次真实上游发送的输入字节、输出上限和协议余量保守预留；故障、取消、进程中断和供应商未返回用量时仍保留预留。它可能早于实际 Token 总和达到上限，不是现金充值或供应商余额。每任务最多 256 次上游发送，输出每次最多 4096 Token，任务令牌七天失效。重试沿用原绑定与剩余额度。

## 用量和费用口径

CDS 与 LLMGW 读取同一份物理请求记录。网关标记“用户 Key”，可按接入密钥和 `cds-user-key` 来源筛选。重试与失败均保留记录；缺失 Token 显示尚未提供，不记为零。

供应商返回可归属的 USD 金额时显示“供应商返回”；存在可靠单价快照时可显示估算；其余为未知。首版用户 Key 路由没有可靠单价快照时只显示 Token，不能把平台转售价格套到个人 Key。供应商账号在其他产品的消耗、余额、免费额度和税费不在本系统统计范围内。

## 管理员启用

| 位置 | 配置 | 用途 |
|---|---|---|
| CDS 全局密钥配置 | `CDS_CODE_REVIEW_GATEWAY_URL` | 网关公开入口的 origin，包含 HTTPS 协议 |
| CDS 全局密钥配置 | `CDS_CODE_REVIEW_GATEWAY_SERVICE_KEY` | 专用于受信 CDS 签发，不与平台模型 Key 混用 |
| 网关 serving | `CodeReview__ServiceKey` | 与 CDS 的专用签发凭据对应 |
| 网关 serving | `CodeReview__Issuer` | 稳定的 CDS 实例标识，同一实例升级不得改变 |
| 网关 serving | `ApiKeyCrypto__Secret` | 已有独立加密主密钥，至少 32 字节；不得临时重新生成覆盖存量 |
| DeepAudit | 原有 `LLM_BASE_URL` 与 `CDS_SERVICE_EMAIL` | 只允许专用服务账号绑定同网关 origin 的任务令牌 |

先发布支持任务绑定的 DeepAudit 和网关 serving / nginx，再启用 CDS 通道。未启用时页面保持平台默认选项。CDS 会先核对 DeepAudit 能力版本，旧引擎无法静默忽略凭据并使用平台额度。供应商地址由服务端固定配置，用户不能借此访问任意服务器。

个人凭据加密存于网关独立集合，不注册到平台、模型或共享模型池。任务只保存不可公开的绑定引用；DeepAudit 持久化的是加密的受限任务令牌。网关 Mongo 运维需为任务的 TokenHash 建唯一索引，并为请求日志的 ServiceKeyId、RunId 保持查询索引。不要在日志、命令参数、截图和报告中放入明文 Key。

## 验证范围

历史真实小项目使用 OpenAI `gpt-4.1-mini`，150 字节、一个 Python 文件，完成 1/1 文件分析并归档，识别了预置 SQL 注入。隔离环境一次调用为输入 1110、输出 710 Token；实际部署后通过 stdio MCP 的另一次线上调用为输入 1110、输出 732 Token（合计 1842），任务 `0ba69f4c4cd042fcbc703cb92113415d`。这两次合计 3662 Token，金额均未知，不能视为整个 prd_agent 审查费用。其余三家只有端点、协议适配和隔离测试，未使用真实供应商 Key 验收。2026-11-10 的文档与验收核对没有再次调用模型；完整交付边界见下方需求台账。
