# 稳定模型标识与模型生命周期 · 设计

> **版本**：v1.1 | **日期**：2026-11-12 | **状态**：开发中

**一句话**：调用方使用稳定能力标识，网关在明确授权和真实验证后更新承接版本，同时保留固定版本调用。
**谁该读**：模型运营人员、MAP 管理员和 MCP 接入方。
**读完能做什么**：理解兼容迁移、定时发现、受控升级和回滚的边界。

## 标识与兼容

模型分为固定版本和稳定能力两类。固定版本保持原有含义，不自动跨代。稳定能力通过独立的公开标识绑定当前承接版本，并可登记旧调用标识作为兼容别名。别名与全部既有公开标识共享组织、模型类型内的唯一命名空间，停用模型的标识仍被保留。

image-2-all 作为画师稳定能力的兼容入口，画师和日光分别维护稳定能力。旧客户端无需更新参数。固定版本不会自行改变含义，但管理员可明确建立旧版本到新版本的迁移计划，直接更新仍用于未来调用的配置。MCP 通知只提供信息，实际选择由服务端同一套解析完成。请求记录同时保留请求标识、逻辑标识及真实执行模型，幂等重试返回原任务。

## 每次升级的完整使用清单

升级必须同时核对目录默认与用途绑定、竞技场、模型实验台、视觉与文学创作的个人设置、业务开放清单、MCP 与开放接口的模型限制、工作流、语音、视频、聊天会话，以及运行部署中的模型默认值。用户面板中保存的选择会影响下一次 MCP 调用，属于活动配置。仅查模型目录不能证明没有遗漏：已经被删除的目录身份仍可能留在业务配置中。

每种使用位置必须登记用途、身份格式和迁移方法。未登记字段、结构异常、扫描失败、运行快照过期或无法自动迁移的用途，均应明确阻止升级完成。独立 SDK、声线账户和已提交的视频任务不能按同名模型直接替换。没有可靠替代关系时，展示缺项并等待明确映射。

先生成持久化计划，再逐条比较配置版本并只更新模型字段；保留所有者、顺序、权限、额度和其他业务设置。并发编辑产生冲突时不覆盖修改。部分成功的计划从原记录继续核对，不能把请求超时当作未执行。迁移后反向扫描所有活动引用；残留不为零或存在未知项时不能显示完成。完成计划还需定时复核，发现后来再次保存的旧引用时恢复阻止状态；证明过期时显示需要重新核对。

直接升级修改活动设置，不重写历史对战、请求日志、既有作品与已提交任务的真实模型记录，也不重新发送结果未知的付费请求。

## 定时发现与继任关系

启用策略后，首次自动检查安排在下一次北京时间凌晨三点，随后按配置间隔检查；手动检查不推迟定时计划。模型目录检查不发起推理。新型号进入待确认目录，不能仅凭名称、数字或供应商返回顺序判定更高级或即将退役。

管理员登记官方资料、前后继型号、能力要求和预算。候选必须先进入现有模型注册体系，具备可用官方线路和可核实价格。缺失映射、能力或价格的候选保持阻止状态，并展示原因。

## 验证、晋级与回滚

可以采用近期真实成功请求作为证据，也可显式授权受保护的自动探测。自动探测必须受任务授权、部署身份、组织权限和预算预占约束。供应商没有请求级美元硬上限时，预占上界只代表保守的内部额度保留，不等同供应商报价；结果未知时不自动重发。

晋级前检查候选配置版本、证据有效期、预算、运行任务及线路状态。仅支持单条启用线路的稳定模型自动晋级；多线路保持人工管理。晋级创建独立线路，旧线路目标不被覆盖。已解析请求继续使用原快照，新请求使用新线路。回滚恢复历史承接线路并保留审计历史。验收冻结候选实际使用的协议与端点；健康采样不会使线路证明失效。配置或授权在验收期间变化时，保留原请求核账锁，禁止重新付费，管理员可用原请求恢复核账。中断切换只补偿已有操作，不借恢复发起新升级。

## 验收标准

旧 image-2-all 调用、显式固定版本、画师与日光、MCP 幂等重试均能核对真实模型。未知型号不会静默替换。检查计划、阻止原因、付费探测、晋级和回滚在管理界面可见。先在 CDS main 验证，再发布正式环境；发布后核对公网入口、真实图片结果及预算记录。

## 已确认的 GPT 6.1 Sol 接入约束

本轮按用户明确选择，将旧阵容迁往 `gpt-6.1-sol`。官方实时目录确认型号存在，实际对话探测确认旧预算字段会被拒绝；只有服务验证通过后才能迁移业务引用。

依据[官方迁移指南](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6.1-sol)，该型号不支持关闭推理，推理模式不接受自定义采样与概率参数；严格参数请求保留原意并在发送前拒绝，普通业务默认参数按已确认契约规范化。工具调用必须使用 Responses 线路，不把 Chat Completions 中的工具请求静默改为纯文字。现有 GPT 5、o 系列和其他上游继续保留各自契约；不按未来型号名称猜测能力。
