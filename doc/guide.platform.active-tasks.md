# 活动任务清单 · 指南

**一句话**：任务台的操作手册 —— 做事的人怎么用（一个列表、点圆圈就完事）、看的人怎么用（谁卡住 / 谁没活）、怎么给别人提建议又不替他排队，以及怎么让智能体帮你填。
**谁该读**：第一次打开任务台的人、要用它带团队的人、要让智能体接进来的人。
**读完能做什么**：照着把一天的活记完、看懂管理视图那一屏、提出并吸取一条建议、给智能体接上任务台的四个工具。

版本：v2（2026-09-16）

---

## 一分钟上手

进去只有一个列表。每行左边一个圆圈：

- **实心那条**是你此刻在做的（同时只有一条）。
- **空心的**是排着队的。
- **点圆圈 = 做完了**。不管点哪一行都是这个意思，下一件会自己顶上来。

做完之后屏幕底下升起一条，问你「做成了什么样」。**可以不填**，旁边永远有「撤销」。
填了的那句会留在历史里 —— 一周后翻回来，看的是那句话，不是一串对号。

## 一天怎么用

| 什么时候 | 做什么 | 在哪 |
|---|---|---|
| 早上 | 看一眼实心那条还是不是你要做的；不是就点别的行尾的「开始」 | 我的任务 |
| 想到一件事 | 「加一件」原地敲，**回车提交，接着敲下一条** | 列表底部 |
| 开完会 | 「粘一段话，AI 帮你拆」，把纪要整段贴进去 | 列表底部 |
| 卡住了 | 点「卡住了」，写清**在等谁** | 实心那行的行尾 |
| 做到一半不做了 | 点「放下」，历史里留痕（能撤销） | 实心那行的行尾 |
| 做完一件 | 点圆圈，顺手补一句「做成了什么样」 | 任意行 |
| 收工 | 什么都不用做 —— 别人看到的就是你列表现在的样子 | — |

## 五个不那么显眼但很好用的地方

**一、标题里写时间，时间会自己被认出来。**
敲「明天交周报」，加进去之后标题是「交周报」，时间是明天。
规则识别不走大模型，所以即时、可预期；认不出来就老实认不出来，不猜。
认出来时下面会显示一条提示和一个「不用」——**它不偷改你的输入框**，你看得见它做了什么。

**二、队列可以直接拖。**
不是只能「提到最前」。按住某一行往上下拖，松手就到位。

**三、点行就能改。**
标题打错了、时间要改、想补一句说明，点那一行进去改，不用删了重建。

**四、删错了能撤回来。**
没投入过时间的是「删除」，投入过的是「放下」（留痕，历史里看得到）。
两条都能撤销，删掉的会回到它原来的位置。

**五、三个视图在左边切，不用来回跳。**
电脑上左侧一条边栏：我的任务 / 大家在做什么 / 做成了什么。手机上是顶部一条分段控件。

## 给别人提建议（和派活不是一回事）

这是最容易混的一处，先记住这张表：

| | 派活 | 建议 |
|---|---|---|
| 谁能做 | 要「管理」权限 | 任何人 |
| 提了之后 | **直接进对方队列** | **什么都不会发生** |
| 谁来决定 | 派的人 | 收的人 |

**提建议**：在「我的任务」右上角点「提建议」，选人、写一句。
或者在「大家在做什么」里某个人那一行点「提建议」。
提过去之后对方队列**不会多出一条活** —— 它躺在对方的收件箱里。

**收建议**：有人给你提了，「我的任务」顶部会出现一条横幅「N 条建议等你吸取」。
点进去可以做三件事：

1. **吸取**：勾几条 → 可选引用几个知识库（术语、模块名对得上）→ 可选补一句自己的要求
   （比如「都拆成半天能做完的」）→ 点吸取。AI 把这些零散的话整理成一条条「我要做什么」，
   **一条条冒出来**给你看，你逐条勾选、可以改标题，**确认了才建**。
   上次选了哪几个知识库会记住，下次默认带上（记在服务端，换台电脑也在）。
2. **放下**：看过了不打算做。留痕，不删。
3. **拿去涌现**：这条建议有点意思但还不知道该做成什么 —— 点那个星星图标，
   它会当种子建一棵涌现树，跳到涌现探索器里去派生。

## 带团队的人看什么

「大家在做什么」一屏，一人一行，**要看的自动排最上面**（卡住的 > 没活的 > 堆太多的）。
每人后面一个数字：队列里堆了几件。

**那个数字是负载，不是绩效。** 只在两端标色：`空了`（该派活了）和堆太多。
中间的人不标 —— 正常就是正常，不该费你的眼睛。
这里刻意没有完成率、准时率、人均产出：那些一出现，下面的人就开始为数字干活。

行尾两个动作：**派活**（直接进对方队列）和**提建议**（进对方收件箱，他自己决定）。
默认派进对方**队尾**，不打断他手上那件；要插队得显式勾「排在最前」。

## 让智能体帮你填

任务台在 MCP 里开了七个工具，权限跟着后台权限位走：

| 工具 | 干什么 | 要哪一档 |
|---|---|---|
| `map_tasks_mine` | 读我在做什么、队列里堆着什么 | use |
| `map_tasks_add` | 往我自己队列尾部加一件（适合把缺陷、PR、告警变成待办） | use |
| `map_tasks_suggest` | 给某人提一条建议（不进对方队列） | use |
| `map_tasks_team` | 读全员在做什么 | manage |
| `map_tasks_assign` | 派一件给别人 | manage |
| `map_debt_list` | 读债务台账：还欠着什么、谁认领了 | use |
| `map_debt_sync` | 把 `doc/debt.*.md` 推到任务台（幂等，只覆盖正文） | use |

一条刻意的边界：**智能体不能结案**。
「做成了什么样」是人对结果的认领，让机器代签，这个字段当天就会退化成「已完成」，
历史也就白留了。同理它也不能替人标记卡住 —— 在等谁是人的判断。

想让机器给人「安排活」，走 `map_tasks_assign` 并承担那份管理权限；
只想让它「提个醒」，走 `map_tasks_suggest`。

## 下半屏：欠着的

列表底下有一块「欠着的」，默认折着。它装的是 `doc/debt.*.md` 里那些工程债务 ——
交付时说好「这次没做、后面要补」的那些事。

点开之后每行是一条债务：前面那串等宽小字（`platform.active-tasks#15`）是它的稳定标识，
对得回台账里第几条；后面跟着「还没人管」或「谁认领了」。点标题展开看现状和「补的条件」。

行尾两个动作：

- **转成我的活**：在你队列尾部建一条任务，备注里自动带上「补的条件」和它来自哪份文档第几条 ——
  接手的人不用回去翻台账就知道什么算补完了。转完这条债务就归你了。
- **认领 / 放回去**：只表态不建任务。适合「我知道这条归我，但还没排到」。

**正文在这里改不了，这是有意的。** 债务的正文跟代码同生共死，它的 SSOT 是仓库里那份
Markdown；界面上把文件路径亮出来，就是为了让你知道该去哪改。在这儿能改的只有
「归谁、什么状态」—— 那两样恰恰是 Markdown 存不住的。

### 让它出现在这一屏

有人（或智能体）改完 `doc/debt.*.md` 之后跑一次：

```bash
python3 scripts/sync-debt-ledger.py --dry-run     # 先看会推什么
python3 scripts/sync-debt-ledger.py --base https://你的站点   # 真推（Agent Key 放环境变量 MAP_AGENT_KEY）
```

智能体那边是同一件事的两个工具：`map_debt_list` 读、`map_debt_sync` 推。
同步是幂等的，反复跑只会更新正文，**不会抹掉谁认领了**。

一条现状：45 份台账里目前只有 9 份接得进来（105 条）。同步只收「主表」——
第一列是 `#`、标题列叫 债务/项/事项 的那张表，一份台账只取一张。
想让自己那份接进来，就把债务整理成一张编号主表。

## 对外的那块看板

有一个不需要登录就能打开的公开看板，默认**脱敏**：
访客看得到谁在忙、谁卡住、谁没活，看不到任务标题正文和在等谁
（任务标题常带项目代号和缺陷细节）。

管理员可以逐档放开（脱敏 / 全文 / 只给一句头条结论），也可以整个关掉 ——
关掉之后公开地址直接 404，不泄露「这里本来有个面板」。

## 常见疑问

**为什么同时只能做一件？**
多线程等于没有焦点。看的人一眼要看到的就是那一件。切换的时候上一条自动结算时长、
退回队首，投入不丢 —— 所以切来切去不会有损失，只是你得明确表态「我现在做的是这个」。

**为什么「卡住了」一定要写在等谁？**
只说「卡住了」别人没法接手。写清在等谁，这条会排到管理视图最上面，才有人能帮你推。

**为什么时间是「截止」不是「预估要多久」？**
预估一旦存在，下一步必然长出估准度和超期判定，那是考核不是沟通。
截止只回答一件事：这件事排在什么时候之前做完。过期不报警、不算准时率，只在那行淡淡标一下。

**为什么不给我看别人的完成率？**
见上面「那个数字是负载，不是绩效」。这是产品选择，不是还没做。

**放下的方案为什么还留在历史里？**
粉饰过的历史没人会回来看第二次。
