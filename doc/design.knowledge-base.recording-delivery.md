# 录音交付与纪要网页

**一句话**：取消录音「处理页 → 结果页」那次跳转，并新增一条不调模型的纪要网页链路——预设模板加自动抽字段加补填表单，产出可分享的只读网页。
**谁该读**：拍板要不要做这件事的人；接手实现的人；验收的人。
**读完能做什么**：知道会多出哪些屏、哪些是新写的、每一步凭什么算过、什么明确不做。

版本：v1.0.0 · 2026-08-29 · 状态：待拍板

可点击的预览包：`assets/prototypes/recording-meeting-note-preview.html`（A 到 Z 全部 26 屏）。

## 为什么做

两件事都来自用户当面提的意见。

**第一件**：录完音要跳到另一个地址看结果，用户的原话是「这就很扯淡，结果页应该是主页吧」。查下来这次跳转不是需求推出来的——代码注释写着，两屏拆成两条路由是因为屏底那颗按钮的文案是「进入结果页」，「同一个地址上说这句话说不通」。**先有跳转，再有理由**。把按钮改成就地的「播放」，跳转就失去了存在的必要。

**第二件**：会后要把结论发给别人对齐策略，现在只能导出一份 .md 自己存档，或者用「一键创作发布」让模型生成一版网页。前者不适合发给人看，后者要调模型、慢且不可控，而会议纪要这种东西**字段是确定的**：谁参加、议了什么、定了什么、谁去做。用户要的就是不调模型那一版。

## 给谁用

| 角色 | 他要什么 | 终点 |
|---|---|---|
| 开会的人 | 会后十分钟把纪要发到群里 | 链接在手上，别人点开能看 |
| 产品 / 运营 | 把几次会的结论摊开定策略 | 几张纪要网页能同时打开 |
| 收到链接的人 | 不注册也看懂这次定了什么 | 手机打开，版式不塌，不要登录 |

## 数据怎么流

四跳，三跳是现成的：

1. 前端带登录凭据请求生成（与现在点「一键整理」同一套鉴权）。
2. 后端在进程内从笔记 markdown 抽字段——**不出进程、不联网、不调模型**。
3. 把填好的模板存成快照，与笔记同库同权限。
4. 访客凭分享 token 打开只读页，复用知识库现有的分享链接验证。

快照与笔记**解耦**是有意的：发出去的东西不该因为作者后来改了笔记而变，访客看到的永远是当时确认过的那一版。

## 字段从哪来

用户选定的口径是「自动抽取 + 一个补填表单」：

- 能确定性抽到的先填好，并标出处：标题来自文件名，时间来自录音时间，参会人来自说话人标签（含用户改过的名字），待办来自摘要的待办节，关键词来自现有词云统计。
- 抽不到的（议题、关键结论这类）进补填表单，**只问抽不到的那几格**，不把已填的再问一遍。
- 允许跳过。跳过的字段在成品里显示「本次未记录」——不留空白，也不让模型编一段像模像样的假话。

这条是硬约束不是排期问题：**这条链路一旦出现任何模型调用，就是走偏了**。

## 关键取舍

| 取舍 | 选了什么 | 代价 |
|---|---|---|
| 录音那一屏 | 合并成同一屏两状态，保留全屏版式 | 不完全等于「结果就是知识库主页」；换来的是不推翻上一轮的设计稿复刻 |
| 模板 | 首版写死四套（建议先做一套跑通链路） | 用户不能自定义版式 |
| 产物形态 | 快照 | 多一个集合；换来「发出去的内容不会被偷偷改掉」 |
| 分享 | 复用知识库分享链接 | 不新增权限模型，撤销与过期沿用现有语义 |

## 验收标准

判据全部由决策者自己核，不需要看代码：

1. 录一段话，全程盯地址栏——地址只变一次。
2. 转写完成那一刻不点任何东西，页面自己从进度态变成结果态。
3. 点生成纪要网页，屏幕上出现**排好版的正文**；停在进度条上不算。
4. 对照抽取结果标的出处，翻回原文能找到参会人与待办。
5. 故意跳过补填直接生成，空字段显示「本次未记录」。
6. 无痕窗口打开链接，不要求登录；手机打开不横向滚动。
7. 撤销后再打开显示「已失效」。

不算数的证据：接口 200、测试全绿、通读自审、旧截图、进度条截图配「已完成」。

## 本期不做

模板编辑器与品牌定制、PDF/Word 导出、协作编辑与评论、用模型补字段、定时或自动发布、访问统计的深度分析。全部进 [debt.knowledge-base.md](./debt.knowledge-base.md)，等真人用过再按呼声排序。

熔断线：连续 8 个提交无功能净增 / 清单外的东西被接进来（尤其是模型调用）/ 碰到「明确不碰」的部分 / 改动文件数超首轮基线两倍 / 同一份方案被重写第 3 次。命中任意一条停下来找人。
