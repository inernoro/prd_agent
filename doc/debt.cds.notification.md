# CDS 通知验收边界

**一句话**：区分服务端可证明的投递与设备侧展示，并保留独立发送进程的升级要求。
**谁该读**：负责通知接入、发布与实机验收的人员。
**读完能做什么**：识别仍需设备或独立运行实例证据的检查项，不把受理回执当成已读。

| 边界 | 当前处理 | 关闭条件 |
|---|---|---|
| 手机与 Apple Watch 实际展示、字号与已读 | 服务端只记录发送与受理，不能证明设备实际显示或已读 | 用户实际设备核对同一演练消息，确认展示范围 |
| 独立手机发送进程 | 保留唯一发送所有权和持久化预算，必须随模板目录部署独立进程，不能为了更新改为第二个发送者 | 运行实例升级到同一提交，真实多事件摘要仍为一句话 |
| 存量报告未带交叉分类 | 保留原报告，显示未分类及环境待确认，可通过报告详情编辑分类 | 按真实证据逐份补录，禁止从标题猜成正式 |
| 监控检查次数与业务调用次数 | 明确分别统计，监控记录不推断用户失败任务数 | 上游或业务调用方提供结构化窗口和独立任务证据后按对应模板接入 |
