# 产品评审智能体版本号主数据 · 计划

> **版本**：v1.0 | **日期**：2026-09-29 | **状态**：执行中

**一句话**：让 T、V 版本号按应用独立分配，并以不可改写的历史快照和公共主数据支撑所有申请人协作。
**谁该读**：负责产品评审、版本申领和历史数据维护的产品、运营与工程师。
**读完能做什么**：知道系统—应用归属、编号规则、历史保护和上线验收分别如何落地。

## 一、核心目标

将产品评审智能体的历史 T/V 登记升级为公共版本资料：一个系统可包含多个应用，一个应用只归属于一个系统；旧登记按应用保留 T 与 V 两条编号序列及其历史快照。原申领页已经实现的字段、企微自动补齐、T 来源和复制模板由产品管理现有正式/内部版本页签承接；后续新申领沿用产品管理的立项/上线流程、产品目录和现有编号规则。旧公共记录可查询系统归属，不搬库、不重编号，也不随产品资料变化改写。

验收以真实预览环境为准：旧登记与快照仍可查询；产品管理 T/V 两页签分别可申领、筛选、导入和查看旧资料，原申领字段与自动补齐、复制能力无遗漏；同编号重复导入受控。旧登记服务端原有按应用序列与快照规则保持不变，产品管理现有新申领编号规则不在本轮改写。
