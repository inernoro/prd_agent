## 验收边界

- 受控响应的浏览器分支测试、真实 Mongo 并发测试与公网真实对象验收分别记账，不能互相替代。
- 浏览器手机尺寸不替代实体手机、软键盘和所有浏览器；刷新或关闭页面后，本地未上传文件不能自动恢复。
- 截图正文描述的玻璃效果问题尚待独立复现，不能据此认定性能或崩溃问题已解决。
- 已证实三次点击产生三次请求，没有证据证明单次点击会触发三次请求。
- 头像先读 R2 后可回退真实 COS 原图，首次 R2 404 可能仍记入控制台；必须核对最终原图解码，不能以占位图作为恢复证据。
