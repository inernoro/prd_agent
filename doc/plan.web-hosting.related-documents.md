# 网页托管关联文档 · 实施计划

> **版本**：v1.0 | **日期**：2026-11-05 | **状态**：已实现，预览验收中

**一句话**：在阅读页顶部用九宫格连接关联文档，允许指定主文档，并在保留独立权限的前提下查看和统一访问范围。
**谁该读**：网页托管产品负责人、开发与验收人员。
**读完能做什么**：掌握交互、权限边界和验收顺序。

## 交付顺序

1. 建立独立于文件夹的关联文档组，保存成员、顺序与主文档；组关系不授予文件访问权。
2. 阅读页顶部增加关联入口；悬浮、点击、键盘均可展开三列九宫格；窄屏采用两列；组内跳转保留访问校验。
3. 作者通过管理面板添加和移除自己管理的文档、调整顺序、更换主文档；移除关联不删除文件。
4. 服务端比较团队、受限分组、公开可见性与有效分享入口，向有管理权限的用户展示差异；同步前提供新增和移除范围预览。
5. 执行一次性权限同步，逐项报告结果；持续继承权限不在首版范围内。

## 权限边界

- 标题、摘要、主文档名称和计数均按当前访问者可见范围返回。
- 分享链接仅授权其原本包含的文件，不能随关联跳转扩大授权。
- 管理操作逐文件校验所有权，权限更新沿用现有发布与私有资料检查。
- 分享链接的密码、有效期、访问统计和凭证不复制到其他文档；差异明确展示，不能把团队同步称为全部权限相同。
- 并发修改检测版本；删除文件后关系读取过滤失效成员。

## 验收标准

- 从网页托管打开阅读页，顶部展开九宫格，进入另一份文件后能继续切换。
- 可添加和移除关联、更换主文档并刷新验证持久化。
- 撤销访问后，关联列表和计数不暴露受限文件。
- 权限差异可预览，取消不修改，执行后结果来自后端重新读取。
- 类型检查、代码检查、权限回归和浏览器交互验证留有实际结果。
