# 债务文档原则：让已知欠账有边界、有偿还条件 · 指南

> **版本**：v2.0 | **日期**：2026-11-22 | **状态**：已落地

**一句话**：在 CDS 保存已确认的工程欠账、影响、偿还条件与证据，方便交接和复核。
**谁该读**：交付时留下已知限制、接手维护和安排治理工作的产品与工程人员。
**读完能做什么**：在项目债务清单记录欠账，沿正式编号查看原始依据和处理历史。

## 登记与回读

从 CDS 左侧「规划」选择项目，进入债务分支的清单。用模块、来源和状态查找债务。智能体通过已授权的 CDS 工程规划技能、MCP 或 `cdscli` 读取、登记或提交待确认提案。 [CDS 工程规划技能](../.claude/skills/cds/SKILL.md) · [工程规划入口](https://cds.miduo.org/engineering-planning?view=debts)

登记已发现且明确暂时接受的问题，记录来源、影响、欠债取舍和可核对的偿还标准。已有证据支持时补齐根因、负责人及计划日期。推测和缺项按记录事实标注，偿还结论附可复核证据。正式台账保留原始来源、当前状态和变更历史。

## 历史依据与其他文档

从 `debt.*.md` 导入的旧记录保留原来源编号和固定 Git 文件定位，已知原始状态随条目保留。遇到旧路径时沿 CDS 记录或文档中的固定版本链接回读。 [旧台账历史版本](https://github.com/inernoro/prd_agent/tree/853023509128fb785541408fd88591db860ce9bf/doc)

已明确安排的工作进入[计划](./guide.doc.pri.plan.md)，重要选择进入 [ADR](./guide.doc.pri.adr.md) 或 [PDR](./guide.doc.pri.pdr.md)，现行约束由[规则](./guide.doc.pri.rule.md)表达。
