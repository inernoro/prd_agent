本次业务目标是从已有分镜素材产出可直接使用的有声短视频，包含画面、配音和整句同步字幕，用户可以在制作台预览、导出，并修改其中一段后重新导出。实现已经推送独立分支；使用方式见[视频创作使用指南](./guide.video-agent.md)，能力边界见[视频债务台账](./debt.video-agent.md)。

## 新环境启动顺序

1. 读取仓库规则及云环境运行技能，确认新环境实际网络策略、凭据就绪状态和工具能力。
2. 拉取上述分支，确认固定业务提交仍可读取，保留新的主干状态作为比较背景。验收范围保持为这一条业务链路。
3. 使用仓库内的 CDS 技能与权威预览地址查询取得本分支实际入口，检查部署状态、冒烟结果和实际运行提交。预览地址只能来自 CDS 响应。
4. 按 acceptance-test-design、acceptance-scenario-orchestrator、create-visual-test-to-kb 的顺序建立本轮设计、场景和证据。新环境重新创建临时材料及登录会话。
5. 核实本人已有镜头和已完成语音。模型新增调用必须有明确预算；未发现预算时采用无费夹具或既有结果，并保留真实供应商验证缺口。
6. 完成桌面双主题和独立触控移动端取证，逐图标注并回读，实际下载检查最终音视频文件。
7. 通过技能归档准入后写入 CDS 验收中心，打开实际报告校验正文、图片、锚点和导航，交付可访问深链。

上一环境的 CDS 请求被出口代理以 403 拒绝，无法取得权威预览入口或归档报告。新环境先以实际请求重新确认，不从旧故障推定新环境也不可用。登录和归档凭据从新环境已有安全配置读取，聊天、文档和报告均不保存密钥。

## 验收场景与完成判据

| 场景 | 真人路径或动作 | 完成判据 |
|---|---|---|
| 进入和导入 | 登录 → 百宝箱 → 视频创作智能体 → 新项目 → 从已有视频开始 | 至少三个已有镜头显示已就绪，无视频模型提交 |
| 逐镜配音 | 选中镜头 → 配音与字幕 → 已有语音 → 采用并同步字幕 | 本人同环境语音可试听和采用，正文及真实时长可见，刷新后保留 |
| 初次成片 | 剪辑成片 → 导出 → 完整成片 → 播放与下载 | 至少三个镜头；实际文件完整解码，画面、配音和字幕对应，预览与下载内容一致 |
| 修改中段 | 为第二镜采用另一段已完成配音，重新导出 | 新成片中段更新，其余镜头保留；没有重新提交模型 |
| 超长语音 | 采用长于镜头可用时间的已有语音 | 明确提示缩短语音或更换更长画面，原采用保留 |
| 导出失败恢复 | 对本轮自有受控夹具制造可恢复故障，恢复后重新导出 | 错误清楚且有恢复入口，原素材和任务身份保留，无新增模型提交 |
| 刷新与重连 | 刷新、短暂断网后重连，从最近作品重新打开 | 同一任务与已采用语音仍可找回，已完成产物可播放 |
| 移动端入口 | 独立触控移动端重新登录并点击导航进入制作台 | 触控入口和核心按钮可达，无横向溢出或遮挡 |
| 移动端成片 | 同一移动端路径打开本人作品并播放 | 画面、字幕、播放和下载可操作，滚动正常 |

按 L2 全链路设计，至少覆盖六个有效用例、桌面明暗主题和两张独立触控移动端证据。建议计划十三张有行为证明力的截图，截图数量不能替代场景覆盖。每条通过断言必须关联本轮真实页面证据，实际媒体校验作为佐证。

导出失败用例仅允许使用本轮自有、可安全恢复的预览夹具；若没有这项前置，记录未执行及关闭条件。禁止通过修改共享对象、全局配置或生产数据制造故障。

## 无费固定脚本与边界

可使用三个五秒的本机媒体夹具，按以下三句短旁白建立一致的验证样本：

1. First, gather the moments that matter.
2. Next, give every scene a clear voice.
3. Finally, share one story, ready to play.

中段修改样本为：Next, bring each moment to life.

本机语音夹具只证明制作台、保存、字幕和合成流程，不代表真实 TTS 供应商音质、账单或可用性。真实供应商验证在明确预算后单列执行。现有字幕按每镜整句同步，历史素材缺少持久摘要时按提示重新导入。
