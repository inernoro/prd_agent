## 产品范围与入口

用户从“智能体接入台”的“语音能力”进入，配置声音预设、提交文字和查看历史；外部客户端使用现有 MCP 连接。生成默认逐字朗读，不自动改写。用户可在“我的资源”的“音频”分类播放、下载同一成品。桌面和移动端都提供分类入口。

第一期支持单段文字、实际音色目录、语速、音频格式，以及具体上游已声明支持的声音指令或情绪。长文拼接、多角色配音、声音克隆、背景音乐和自动改稿不在第一期。原始 PCM 可供后续程序处理，浏览器是否支持播放取决于格式，常规试听建议选择 MP3。

## 配置与能力发现

配置分为当前环境、网关上游连接、语音能力和用户声音预设四层。网关继续管理服务地址、账号凭据、地域、资源标识和真实协议；语音能力只引用网关已开放的逻辑模型，并保存具体上游资源绑定。预设只保存用户对某项能力的选择。

环境由服务端决定，不接受客户端指定。开发、生产及分支预览不相互读取语音配置、预设、历史或字符额度。分支配置使用稳定的项目与分支身份，后台任务认领仍包含提交版本，避免不同构建抢占任务。

同一个品牌不等于同一种能力。同一模型池也可能包含不同账号、地域或资源的线路。提交时固定实际上游资源，执行前复核逻辑模型、协议及配置版本，不因健康调度改用另一套声音资源。管理员更换绑定是显式配置变更，会使旧预设失效。

| 能力 | OpenAI 语音协议 | 豆包 HTTP V3 语音协议 |
|---|---|---|
| 基本输入与产物 | 文字、音色、音频 | 文字、音色、音频 |
| 认证和账号资源 | 网关管理 Bearer 或兼容连接 | 网关管理单密钥或双凭据，并显式配置本账号资源标识 |
| 音频响应 | 二进制音频 | 逐行消息中的音频分片，必须收到成功结束标记 |
| 语速 | 在协议范围内再按模型收紧 | 倍率转换成对应的语速参数 |
| 专属参数 | 模型支持时提供声音指令 | 音色支持时提供情绪 |
| 格式 | 仅开放管理员核实支持的格式 | 首期 MP3、Ogg Opus、PCM，不拼接流式 WAV |

能力目录给出音色、语言、试听、格式、参数范围、默认项及不可用原因。管理员填写真实开通的音色，不按模型名称推测特性。不支持的参数直接拒绝。临时故障保留目录和恢复说明，不静默换模型或音色。

通用 MCP 工具负责查询能力、生成、查任务、找历史和读写声音预设。专属参数仅在对应能力声明支持时使用，参数名称必须准确，不能静默丢弃。未来存在独立输入或执行流程的特性，再作为单独的专属工具注册。

## 任务与资产的数据流

一次生成依次经过参数校验、持久化入队、额度与资源校验、上游合成、加密保存、完成。关掉客户端不取消服务端任务。只有音频已保存且资产记录可查询，任务才完成。

| 数据 | 保存内容与用途 |
|---|---|
| 环境配置 | 能力名称、逻辑模型、实际资源、音色和参数声明、额度、配置版本 |
| 声音预设 | 用户、环境、能力版本、音色、格式、语速、专属参数及编辑版本 |
| 生成任务 | 用户、来源客户端、原文、提交指纹、配置快照、进度、错误、实际路由、网关日志关联及资产引用 |
| 字符额度 | 用户与能力在当前环境的原子额度；按 UTC 日计字符，跨午夜保留仍在运行的并发槽位 |

请求标识在用户、客户端和环境内去重；同标识异内容返回冲突。预设与平台配置都使用版本检查，删除后重建相同能力标识也不能使旧预设重新有效。

音频加密后写入现有资产存储，不返回上游临时地址或公开明文对象地址。播放下载由 MAP 校验用户归属后读取并解密；浏览器使用带认证的下载通道，MCP 客户端继续携带自己的接入凭据。必须持久化并备份部署的数据保护密钥，否则重启或迁移后无法解密历史音频。

调用记录关联语音历史入口；即使智能体没有继续轮询，后台完成后仍自动出现在个人音频资产中。撤销客户端授权不删除既有资产。

## 失败、费用与访问边界

查询与生成分别授权，平台配置另需管理权限，用户只能读写自己的历史与预设。语音管理不对外部 MCP 开放。新能力出现在授权目录中，已有手动授权的客户端需要显式增加授权。

平台字符额度是防止失控调用的使用限制，不冒充供应商费用。真实账单由网关实际用量与价格依据决定。未调用上游的失败释放字符额度；上游已受理、成功或状态未知时不能假定零费用。查询进度不会重复生成。超时或执行中断导致结果未知时保留待核查状态，不自动跨上游重发。

资产保存失败时在内存中重试保存同一音频，不重新合成。已写对象但任务状态尚未完成时，可按已持久化对象引用恢复。进程丢失且没有可恢复音频时明确失败或待核查；第一期不声称所有供应商都具备结果恢复接口。

原文只进入受用户归属保护的业务历史，普通 MCP、HTTP 和网关审计不复制完整朗读稿、音频或凭据。上游成功、业务失败、解析失败与传输中断都保留可关联的脱敏证据。

## 验收标准

1. 同一条普通朗读需求分别通过 OpenAI 和豆包真实账号生成，实际音色与输出格式符合各自能力声明。
2. 声音指令与情绪分别在支持的上游生效，跨上游误传参数被拒绝；切换上游不带入另一家的专属参数。
3. MCP 创建任务后断开连接，后台仍完成；用户在历史和音频资产中找到同一成品并播放、下载。
4. 同请求标识并发重试只生成一个任务；同键不同内容被拒绝。
5. 不同用户、环境、无权限及撤销授权的访问被拒绝；对象存储中只有密文。
6. 能力变更、音色下线和预设编辑冲突有明确提示，不静默替换配置。
7. 额度并发、跨午夜、进程中断与保存失败后补偿可复现；未知结果不触发第二次付费调用。
8. 同提交构建、协议测试、数据库集成测试、明暗主题和桌面移动端真实页面完成验证，证据与模拟测试分别说明。

## 真实环境验证记录

2026-11-06 在专用测试账号、当前分支预览环境完成 OpenAI 真实 MCP 合成。Nova 音色、1.1倍语速及中文声音指令得到7.968秒的MP3；同一个任务可从生成历史、音频资产和鉴权下载找回。重复提交返回同一任务，没有再次合成。网关记录实际模型与固定线路，审计省略音频内容。

真实验证发现并修复了存储目录未注册的问题，回归现已使用真实存储路径校验，并覆盖两种协议的本地加密保存和新实例读取。豆包的资源标识已补入网关配置入口，但本环境尚无真实豆包凭据和资源，不能把配置回归当作真实合成通过。
