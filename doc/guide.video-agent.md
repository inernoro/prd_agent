# 视频创作 Agent 使用 · 指南

> **版本**：v1.1 | **日期**：2026-11-12 | **状态**：已落地

**一句话**：在视频制作台中采用已有镜头、配音与同步字幕，预览并导出同一条成片。
**谁该读**：内容运营、自媒体创作者、市场营销及本次功能的验收负责人。
**读完能做什么**：制作一条有声短视频，修改其中一段，并在失败后继续导出。

---

## 入口和准备

登录后点击「百宝箱」→「视频创作智能体」。已有项目和制作任务保存在「最近作品」，完成的任务可以重新打开预览与下载。

制作台保留故事分镜和单镜直出两条生成路径。本文优先说明无需重新生成画面的已有素材路径。视频、语音的新增模型调用仍使用当前账号的权限、能力配置和费用额度；验收没有明确付费预算时，仅使用已有素材与已完成的语音。

## 从已有素材开始

1. 点击「新项目」，填写作品名称。
2. 点击「从已有视频开始」，按镜头顺序选择视频文件。
3. 等待兼容处理，进入制作台后确认左侧镜头均显示「已就绪」。

支持 MP4、MOV 和 WebM。一次选择 1 至 16 个视频，单个不超过 100MB，合计不超过 300MB；每段时长为 0.1 至 60 秒，画面尺寸不超过 4096 像素。文件必须包含可解码的画面。导入不会提交视频模型，也不会删除原项目的历史任务或素材。

## 配音与字幕

1. 选中左侧的一个镜头，点击顶部「配音与字幕」。
2. 在「已有语音」中选择本人在当前环境已完成的语音，可先试听。
3. 点击「采用到此镜头并同步字幕」。面板显示已采用正文和真实时长。
4. 对其余镜头重复上述操作。

也可在该面板输入本镜头脚本，选择已有语音能力和声音后点击「生成配音」。生成可能收费；任务完成后仍需明确采用。未配置语音能力或没有相应权限时，面板会说明原因。刷新只读取已有任务与配置，不自动提交模型。

字幕使用所采用语音的正文，按该段完整发音时长显示；当前按每镜整句同步，不声明逐字对齐。配音超过镜头可用时长时会明确拒绝，请缩短配音或采用更长画面后再试。历史镜头缺少持久素材标识时，按提示重新导入。

## 预览、导出和修改

1. 所有镜头就绪后，点击「剪辑成片」→「导出」。
2. 等待下载素材、合成与保存完成，查看「完整成片」。
3. 点击播放，检查画面、完整配音和字幕；「下载」取回播放器展示的同一个 MP4 文件。

字幕烧录进画面，同时保留字幕轨。选择左侧镜头可以回到镜头编辑；为其中一段采用新的语音后，旧成片会失效，重新导出即可取得更新后的成片。再次导出复用已采用语音和已有画面，不重新提交模型。

## 失败与继续制作

| 遇到的情况 | 操作 |
|---|---|
| 语音仍在生成或提交响应不明 | 刷新语音与状态，查看原任务；不要反复新建语音 |
| 语音生成失败 | 阅读错误，修改脚本后明确重新生成，或采用其他已有语音 |
| 配音或视频资产不可读 | 恢复存储或按提示重新采用、导入该段素材 |
| 导出失败 | 原镜头和配音保留，处理提示原因后点击「重新导出」 |
| 页面刷新、短暂断网或服务重启 | 重新打开原制作任务，刷新状态；已完成的成片可继续预览与下载 |

本次未扩展背景音乐生成、复杂转场或新视频模型。当前完成范围和仍需公开预览、真实供应商验证的边界见[视频债务台账](./debt.video-agent.md)。
