# 模型工作台与上游绑定 · 设计

**一句话**：把模型列表改成主要操作面，用户可自定义名称、绑定与测试上游，并在完整依赖检查后快速清理停用项。
**谁该读**：维护模型的管理员、产品负责人以及负责网关和 MAP 调用链的研发。
**读完能做什么**：核对首版操作范围、保护边界与验收条件，并通过交互预览确认页面效果。

## 用户能完成什么

模型页优先展示模型。标题、搜索、筛选和操作收在紧凑工具栏，统计、原理和升级详情按需打开。列表连续向下加载，保留搜索条件和滚动位置，取消逐页操作。停用项进入待清理视图，避免挤占日常在用清单。

统一使用一个「新建模型」入口，在同一面板内选择自定义创建，或从已配置上游的模型清单登记。显示名称允许自由命名；公开标识仍需唯一且适合外部调用，名称修改不能悄悄破坏 MCP 和业务引用。

每个模型行直接提供绑定上游、测试和删除。绑定面板同时呈现上游、上游实际型号、调用方式及测试结果；上游列表提供脱敏密钥标识；一个模型可以有多条线路。只有已注册适配器可供选择，fal 和 OpenRouter 不因接口外观相似就被当成同一协议。参数改变后上一次测试失效；按保存后的线路重新验证。

## 数据与权限

沿用现有模型、线路、适配器和认证，不新增服务容器或一级导航。浏览器的配置操作由现有会话和配置写权限约束；实际探测经过网关和有限任务许可，再由服务端使用对应上游密钥。浏览器只接收脱敏标识。

模型绑定测试区分配置校验、HTTP 连通和真实服务验证。获取模型清单成功不等于生图或推理成功；涉及付费的样例测试在点击前说明数量与用途，保留实际命中线路和产物证据。未知结果不自动重发。

上游列表展示最近真实调用的结果和时间。额度不足与限流分开；该状态不是实时余额。密钥标识只向已有配置写权限的人下发，换密钥或配置更新前的失败不能直接描述当前密钥。

## 快速清理而不破坏业务

列表允许选择多个模型，一次预览确切清单。没有活动引用、默认职责或在途任务的停用项可以直接进入清理；有引用的项目列出使用位置与迁移动作，不用反复尝试删除猜原因。

永久删除仍在最后执行前确认，展示确切对象和线路数量。画师、日光、稳定公开标识、历史作品和请求记录受现有保护。批次执行回报每项成功、阻断和未执行结果；执行前重新检查依赖；单项并发变化被拒绝，网络结果未知则停止后续删除，不扩大旧授权。首版不把停用自动解释成可永久删除。

## 分阶段与范围

先交付余额识别、脱敏标识和 MCP 文学批次数量修复，再完成模型列表布局、绑定测试与批量清理。交互预览使用明确标记的示例数据，不代表新供应商已接入。

本次逐线路服务测试已复核执行范围：仅新增明确点击的单线路入口，复用现有一次许可和金额合同，锁定原线路并重验操作者、配置指纹及价格；不修改金额授权规则。当前真实服务测试覆盖已登记规格的 OpenAI 兼容聊天、Anthropic Messages 和 2.6 图片；其他适配器仍可绑定和测试 HTTP 网络，未登记近期价格与安全请求规格时明确阻止付费测试，不能把它标成服务通过。

工作台预计约十二个业务文件；超过二十四个、触碰登录鉴权或金额授权、连续三个实现提交没有新增可验收路径时，停止扩展并复核范围。回收站、任意脚本协议和自动采购不在首版。布局可以独立回退；永久清理无法依靠代码回滚恢复。

## 验收条件

管理员从模型页完成自定义名称创建和从上游登记；在模型行绑定、改变调用方式、查看真实测试结果并保存。错误协议必须明确失败，测试结果不能沿用到修改后的参数。列表无大段头尾说明、无逐页导航，明暗主题与窄屏均可用。

选择无引用和有引用的停用项一起清理，确认前能看到整批对象；前者删除，后者保留并给出依赖。正式执行前仍需固定完整对象清单。

普通用户能在 MAP 找到模型并拿到最终作品；运营能完成绑定并取得测试产物；管理员能定位额度不足的上游密钥并拿到恢复后的成功记录。画师、日光和已有 MCP 各跑通一条真实路径，作品刷新后仍在。接口成功、编译绿灯、旧截图和进度条不能单独作为验收通过。
