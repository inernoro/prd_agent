# 产品管理评审能力归位 · 计划

> **版本**：v1.0 | **日期**：2026-10-19 | **状态**：执行中

**一句话**：将方案评审、需求评估和完整的 T/V 申领能力收敛到产品管理界面，保留原业务能力和历史数据。
**谁该读**：负责产品管理、方案评审和版本申领的产品与工程师。
**读完能做什么**：按菜单入口和验收路径判断这次归位是否完整。

## 一、核心目标

登录后从产品管理即可完成原产品评审智能体的全部任务：独立“评审”菜单承载方案提交、结果、全部提交、排行榜、通知配置和维度配置；“需求”页按钮进入需求评估；“版本”现有正式/内部两个页签分别承载 V/T 申领、公共与产品记录、筛选、历史导入和快照。新申领沿用产品管理既有立项/上线流程，以产品目录为应用选择来源，补齐旧页的全部申领字段、企微内容自动回填、T 来源兜底、结果复制和完整模板；不再另设系统—应用或公开申领页面。旧记录和快照保留，不搬库、不重编号；旧链接兼容。

版本号申领单独授权：仅有该权限的人可在产品管理的 T/V 页签选择全部产品并完成申领所需的方案评审，不因此获得产品管理其他页面、通用评审列表或配置权限。
