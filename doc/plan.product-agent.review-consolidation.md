# 产品管理评审能力归位 · 计划

> **版本**：v1.0 | **日期**：2026-10-19 | **状态**：执行中

**一句话**：将现有方案评审、需求评估和版本号申领归入产品管理的对应菜单，同时保留原业务能力和历史数据。
**谁该读**：负责产品管理、方案评审和版本申领的产品与工程师。
**读完能做什么**：按菜单入口和验收路径判断这次归位是否完整。

## 一、核心目标

登录后从产品管理即可完成原产品评审智能体的全部任务：独立“评审”菜单承载方案提交、结果、全部提交、排行榜、通知配置和维度配置；“需求”页按钮进入需求评估；“版本”页入口进入 T/V 版本号申领、记录和系统—应用资料。旧链接仍可用，历史数据不复制或重编号。
