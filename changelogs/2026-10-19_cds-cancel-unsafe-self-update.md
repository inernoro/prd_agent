# CDS 自更新超时取消，保护其他项目

- 自更新、强制同步和仅重启共用安全等待：先等待部署、发布与分支写操作结束，超时取消本次更新与重启。
- 安全等待移到代码切换和前后端产物替换之前，取消后保留当前运行版本，不制造“候选已切换、旧进程仍运行”的状态。
- 取消后立即释放部署入口并清除等待状态，历史记为“已中止”；零等待和过期心跳不能绕过保护。
- 等待超时的历史记录显示“已中止 / 未执行重启”，避免误读成代码校验失败或旧记录缺失。
- 已受理排队部署可以通过原有已验证内部重派继续执行，新部署在更新窗口收到明确的稍后重试响应。
- APP02 被中断的入口代理按原提交恢复，同时恢复其页面与 API 上游；保留原私有数据和运行配置。
- 回归覆盖三个真实 HTTP 路由、无部署记录的分支操作、文件保持、未触发重启、排队重派和取消后开闸。
