## 取得并还原完整包

仓库是 inernoro/prd_agent，分支是 codex/testing-methodology-tutorial。本地 Agent 可以读取 PR 最新分支，只下载本目录所需文件；如果检出仓库，请保留用户未提交修改，必要时使用独立 worktree。

完整 ZIP 超过 GitHub 单文件上限，故拆成 testing-tutorial-handoff.zip.001 起的普通二进制分片，每片至多48 MiB。实际分片列表、文件长度和 SHA-256 见 handoff-manifest.json。它们不是独立压缩包，无需 Git LFS，不要逐片解压。

Agent 执行 python3 restore.py --output /本地制作目录/testing-tutorial-handoff.zip。脚本核验每片及完整 ZIP 的长度与 SHA-256，验证失败不会替换已有目标文件。还原成功后由 Agent 解压，打开 index.html 和配套审阅页；托管视频时使用包内支持 Range 的服务。
