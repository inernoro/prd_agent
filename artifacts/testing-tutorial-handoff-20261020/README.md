## 取得并还原完整包

仓库是 inernoro/prd_agent，分支是 codex/testing-methodology-tutorial。本地 Agent 可以读取 PR 最新分支，只下载本目录所需文件；如果检出仓库，请保留用户未提交修改，必要时使用独立 worktree。
