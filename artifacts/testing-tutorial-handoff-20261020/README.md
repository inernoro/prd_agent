# 本地 Agent 续作入口

用户无法从云端会话下载文件，因此将完整交接包随本分支提交到 GitHub。学员无需操作代码；以下步骤由接手的本地 Agent 执行。

先读同目录的 `本地Agent交接提示词.txt`，其中保留用户要求、反馈、已完成事项、配音问题和后续制作顺序。第一、二章内容已获认可，其余章节等待审阅；本包的无声视频用于画面审阅，正式中文配音尚未完成。

## 取得并还原

本分支是 `codex/testing-methodology-tutorial`，仓库是 `inernoro/prd_agent`。本地 Agent 可检出本分支，或通过 GitHub 下载本目录全部文件。不要覆盖用户本地未提交的修改；必要时使用独立 worktree。

原 ZIP 为 137.3 MiB，超过 GitHub 单文件 100 MB 上限，故按顺序拆成三个普通二进制分片，每片至多 48 MiB。它们不是独立压缩包。无需 Git LFS，也不要逐片解压。

Agent 执行 `python3 restore.py --output /本地制作目录/testing-tutorial-handoff.zip`。脚本逐片核验长度与 SHA-256，合并后核验完整 ZIP；验证失败不会替换目标文件。生成文件与原交接 ZIP 逐字节相同，再由 Agent 解压并继续制作。
