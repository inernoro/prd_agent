本分支完成了可供审查的单库问答接线及本地工程验证，**真实模型效果和真实预览用户路径尚未验收**。当前阻塞是执行环境对 MAP/CDS 的网络访问被拒绝，以及浏览器运行时无法启动；不能把这些阻塞推断为线上仍缺 embedding key。

基线为远端默认分支 main 的 `3035365def7b30a28309b89a21756717fda846dd`。变更覆盖既有网页提问、知识库只读权限、向量底座与文档后台 Worker；没有创建新应用、平行模型配置、自动数据库索引或付费设施。未合并、未创建 PR、未发布生产。

## 使用与真实验收路径

正常登录 → 左侧“网页托管” → 打开本人创建的网页预览 → “向我提问” → 在“回答依据”选择已有可读知识库 → 提问 → 阅读原文摘录 → 点击“打开原文”。链接定位到阅读器的对应知识库和条目，阅读器继续执行权限检查。首版只输出可验证摘录，不自由生成综合结论；无充分依据应拒答。

知识入库继续使用原有知识库创建和上传入口。索引、查询与依据核对复用统一模型网关和持久化后台任务，只刷新用户明确选定的单库，每次按内容哈希复用向量。最多一百篇文档、三千块和一百万字符；容量不足时明确失败。任务观察最多一百二十秒，超时不返回旧结果，也不取消已提交 Worker。更新、删除和撤权在下一轮重新读取；本轮输出前发现变化就停止回答。

**真实预览地址未取得**：按仓库要求执行权威 `cdscli --human preview-url`，请求因 HTTP CONNECT 403 被拒；没有根据分支名拼接地址。已尝试用云桌面打开实际 MAP，浏览器工具返回 `the gaas-browser node_repl sandbox cannot be disabled`，导航未发生。因此正常登录、页面渲染、浅深主题、实际引用点击和公网时效都没有通过结论。

## 八维交接

| 维度 | 结论与边界 |
|---|---|
| 入口 | 复用网页“向我提问”，站内本人网页可选单库；分享和团队访客不可携带知识库权限 |
| 文档 | 两份债务已按当前源码与阻塞更新；供应商历史调查不再被误当当前运行事实 |
| 契约与数据 | 提问可带选定库；引用与检索元数据作为 SSE 事件返回；新索引代次写入既有向量集合，知识候选不从通用 Run 回读或事件流暴露 |
| 测试 | 本地工程验证通过，真实模型与浏览器验收未过；必须按固定数据和实际入口补齐 |
| 发布与运维 | 只推独立分支；无生产发布、迁移、定时全库任务、数据库自动建索引或新付费设施；CI 与预览状态需远端复核 |
| 安全与隐私 | 先鉴权再读正文；不以网页 owner 替访客读库；本人站点限制避免私有知识进入别人的站点会话审计；切换依据清历史，前轮答案不进入本轮模型上下文 |
| 已知风险 | 未解析正文暂时跳过且无覆盖率提示；真实召回/拒答与延迟未测；模型漂移失败关闭；跨库与大库未实现；未新增网页问答的断线恢复入口；后台任务继续运行，但页面不会自动找回该次结果 |
| 后续行动 | 环境负责人开放测试域名网络并恢复浏览器运行；工程负责人核实统一网关凭据与绑定；验收负责人跑固定集、人工复核和真实路径，再归档验收知识库。上述完成前不关闭 K-2 |

此报告属于阶段性交接，不构成发布、合并或全项验收通过的授权与结论。
