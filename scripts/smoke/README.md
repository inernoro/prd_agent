# 端到端冒烟脚本

**一句话**：把「让用户手工点一遍再截图反馈」压成一条命令，判据全部机械可核。
**什么时候用**：改完某条端到端链路、准备说「完成」之前。

这里的脚本跑**真实浏览器 + 真实后端 + 真实模型**，因为这类链路的缺陷（判定卡住、
刷新后布局塌、元素在低缩放下互相遮挡、层数对不上、导出 401）纯函数单测一个都照不出来。

## visual-layering.mjs —— 视觉创作「AI 分层」

```bash
MAP_SMOKE_USER=<账号> MAP_SMOKE_PASS=<密码> \
  node scripts/smoke/visual-layering.mjs
```

默认打当前分支的 CDS 预览域名（走 `cdscli --human preview-url`，不自己拼）。
常用可选项：`SMOKE_BASE` 指定被测地址、`SMOKE_SRC` 换待分层原图、`SMOKE_OUT` 换截图目录、
`SMOKE_TUNNEL_CROSS_ORIGIN=1` 在「Chromium 到不了外网」的沙箱里由 Node 代取跨域响应。

退出码：`0` 全过 / `1` 有断言失败 / `2` 环境问题（没跑成，不代表功能坏）。

覆盖的判据（每条都能在把对应修复撤掉时变红）：

| 判据 | 它防的是哪次真实事故 |
|---|---|
| 分层完成且面板真的出行 | 拿 spinner 冒充完成 |
| 每行主标题互不相同 | 名字由超长提示词拼出、被截断成同一串 |
| 事实行随层变化且带本层覆盖率 | 三行副标题全是同一个文件名 |
| 没有一行停在「正在识别内容」 | 判定读到未刷新的跨域地址，最后一层永远卡住 |
| **各缩放档位都不遮挡** | 低倍下 Frame 头部 / 图层面板按钮 / 分层中标记三者叠在一起 |
| 刷新后同一 Frame 内图块等大 | 排版尺寸没落盘，刷新后塌成碎块 |
| PSD 非空且层名互不相同 | 导出走同一条读图路径，401 时静默失败 |
| 运行期间没有 401/403 | 读同源资产没带登录凭据 |

## 写新冒烟时的两条纪律

1. **判据要能变红**。写完把对应修复临时撤掉跑一遍，用例不红就是它没在测你以为的东西
   （见 `.claude/rules/predicate-and-wiring-discipline.md` 形状 4）。
2. **绝不伪造前提**。历史教训：harness 给所有跨域响应注入了 `access-control-allow-origin`，
   而真实对象存储并不给这个头——伪造的许可把「跨域读像素被拦」整个藏了一轮。
   代取字节可以（只换搬运工），补权限不行。
