模型网关是所有大模型调用的统一入口。它按调用用途码把请求路由到获准的模型池，并统一记账与限流。应用侧只认一个地址和一把密钥，换模型不用改代码。

OpenAI /v1/chat/completions 
REQUEST_ID="quickstart-$(date +%s)-$RANDOM"
curl "http://localhost:5627/v1/chat/completions" \
  -H "Authorization: Bearer $LLMGW_API_KEY" \
  -H "X-Gateway-Source: external" \
  -H "X-Gateway-App-Caller: xiaomi-speaker.command-intent::chat" \
  -H "X-Gateway-Dry-Run: quickstart" \
  -H "X-Request-Id: $REQUEST_ID" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "auto",
  "model_policy": "auto",
  "messages": [
    { "role": "user", "content": "Reply with OK" }
  ]
}'
示例默认带 X-Gateway-Dry-Run: quickstart，不产生上游费用。
