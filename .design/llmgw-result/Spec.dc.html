一、八处改动
按版面从上到下
位置现状改为
顶部横条 两条通栏绿条叠着；第二条是纯绿底通栏 合并成一条。卡片底 + 左侧 2px 成功色竖线，验证结果收成第二行「小圆点 + 一句话 + requestId 链接」。纯色通栏是 toast 的语言，不该常驻页顶。
一次性密钥 三等分之一，藏在「接入信息」页签里 独占一行、提到页签之上常驻。码 17px mono 650，主按钮 44px 高（比页面其它按钮高一档）。两个理由：它是全屏唯一取不回来的东西；而且切到 cURL 页签时它现在会被切走。
页签 三张等宽大卡，内边距与内容卡相同，选中态只有一圈淡描边 降级成分段控件：轨道 --bg-elevated + 3px 内衬，按钮 36px 高、宽度按内容、左对齐。选中态 accent 描边 + accent-soft 底 + 加粗。
接入地址 / 调用用途 与密钥三等分，且三卡不等高、底边参差 降为两张并排配角卡。grid 默认 align-items: stretch 保证等高；注释用 margin-top: auto 贴底，两卡底边必齐。
下半屏空白 接入信息页签只占上半屏，下面 40% 全空 内容区 min-height: 320px，并把「再测一次 / 排障」收进来补齐节奏。
再测一次 / 排障 孤零零一行折叠挂在页面最底 收进内容区，成为一张与配角卡同规格的折叠卡，行尾补一句三环归因的提要。
cURL 工具条 五样东西挤一条；两句说明一左一右，右边那句贴着右边缘 拆成三行：第一行只读类型 chip + 模型；第二行是输入；第三行是两句说明合成的一段 + 安全试跑 / 真实调用。代码块的浮动复制按钮收进 header 行。
试跑输入 / 输出 只能「上传文本」传个文件，正文写死 Reply with OK；模型返回飘在代码块上方，跟发出去的东西没有配对关系 改成上输入下输出。输入是可直接写的 textarea（上传降级成行尾一个次要按钮），输出块紧贴其下，同宽、同圆角、同 88px 最小高，中间只隔一条动作行。输出块左侧 2px 竖线区分方向（接收中走 accent，完成走 ok），行首标 1.9s · 实际执行 <模型> 与 requestId。空态也占满 88px，跑起来页面不往下跳。输入内容同时进 cURL 片段的 content，两边永远是同一次请求。三态见「试跑输入 / 输出」画板。

三、两个容易漏的实现点
密钥移出页签是结构改动，不只是换个位置。它要从 resultTab === 'access' 的分支里提出来，放到页签容器之外——否则切页签照样会把它卸载掉。
浅色档嵌套底必须换 --bg-base。浅色下 --bg-elevated 与 --bg-surface 同为 #ffffff，代码块、分段控件轨道、配角卡在白天会和卡片糊成一片。上一轮已按这个办法修过引用块，这一屏照做。
