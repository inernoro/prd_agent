# MAP 轨道工作场交接清单

**一句话**：以视频中的身份确认、圆环扫描与空间揭幕为锚点，连接 MAP 登录页和既有工作台。
**谁该读**：设计、产品与后续维护者。
**读完能做什么**：理解视觉取舍，复核真实用户路径与验证边界。

设计参考为同目录 concept.png；用户授权自主决定设计与实施，并未逐项确认生成概念图。参考视频由 rea-video 本地拆解为四段，Codex 看图复核全部镜头；人物素材与音频来源无法仅靠帧图确认。实现采用原生矢量装置，未搬用参考视频的品牌与人物。

## 设计对照

| 对照点 | 最终实现与刻意取舍 |
|---|---|
| 页面结构 | 登录采用左右双区，左侧标题与轨道，右侧开放表单；手机改为上下布局 |
| 文案 | 标题“让想法，进入现实。”、主按钮“进入 MAP”；补充现有系统所需的 SSO、错误、首次改密状态 |
| 字体 | 大标题与紧凑正文分级，表单辅助文字 12–13px；使用既有字体资源 |
| 配色 | 登录浅色采用冷白、蓝色轮廓与深墨文字，暗色使用既有语义 token；工作台保留既有卡片主题素材 |
| 装置 | 真实 SVG 线框与刻度，指针倾斜、轨道旋转、真实请求时加速；支持减少动态效果 |
| 工作台 | 使用真实问候、搜索、近七日数据、在办工作、动态和能力目录；概念图中的虚拟导航、指标与项目示例不进入产品 |
| 动效 | 工作台约 850ms 开场揭幕，交互始终可用；不强制播放原视频的 19 秒片头 |
| 入口 | 继续使用登录与首页原有入口，无新导航、权限或服务接口 |

## 八维交接

| 维度 | 说明 |
|---|---|
| 入口 | 登录 → 点击“进入 MAP” → 工作台；搜索和既有目录继续进入各业务页 |
| 文档 | 本文件保存设计取舍与验收事实，未向产品添加交付记录入口 |
| 契约与数据 | API、权限、SSO 状态校验与回跳、首次改密业务流程不变 |
| 测试 | 自动测试与浏览器操作均已实际运行；外部 SSO 提供方登录和首次改密未用真实账号执行 |
| 发布 | 仅分支预览，未发布生产；同提交 CI 与公网验证结果由交付消息给出 |
| 安全 | 不保存或输出账号密码；临时浏览器凭据桥接文件使用 0600 并已立即删除 |
| 风险 | 动效可由系统减少动态效果关闭；原有服务额度通知属于已有系统数据，不代表本次登录失败 |
| 后续 | 后续维护者按同一真实入口复测；外部 SSO 与首次改密需要具备对应条件的账号，不应为验收重置现有用户密码 |
