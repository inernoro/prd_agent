二、第 2 步分三层
层与层之间 28px + 必要处一条 1px 分隔线
层装什么版式要点
层 0 · 步骤头 序号 / 标题 / 副标题 / 改那句话 标题独占首行，「改那句话」margin-left:auto 推到行尾并撑成 32px 高的点击区；副标题落第二行、左缩进 40px（28 序号 + 12 间距）与标题文字对齐。旧版四样同基线是撞车的根因。
层 1 · 你说的那句话 小标签 + 引用块 2px 强调竖线 + --bg-elevated 底（浅色档换 --bg-base），内边距 14/18，行高 1.7。
层 2 · 系统推出来的结果 将颁发 / 码 / 来源 chip + 理由 / 调用类型 码 17px mono 650——本屏最大的字。眉标、码、来源三行纵向叠，不再左右两端拉开。调用类型拆出去成为一个带标签的独立字段，这是「中间空着」的解法。
层 3 · 你要做的决定 高级折叠 + 提示 + 两个按钮 上方一条 border-top + 28px 内边距把它和「系统给的」隔开。提示 flex:1 1 320px、按钮组 flex:none：窄屏自然折两行，按钮不会被挤扁。
三、字号落点（七档一个不多）
档位token本设计里用在哪
20px--fs-title页面标题（Quickstart / 服务网关设置）
17px--fs-metric只给颁发的那条码。整屏唯一的 17px，它就是这一步的产物
15px--fs-heading步骤标题、卡片分区标题、三选一卡片的名字、降级态两段判定的值
14px--fs-body引用块正文、只读事实的值、窄屏按钮文字
13px--fs-secondary副标题、理由句、底部提示、按钮文字、文字链
12px--fs-caption字段标签（你写的 / 调用类型 / 归属团队…）、chip、来源标注
11px--fs-micro本设计没用到。下限留着，别为了塞字往这一档挤
四、顺手要修的两个既有问题
浅色档的嵌套块是隐形的：INSET_BLOCK 用 --bg-elevated，而浅色档里它与 --bg-surface 同为 #ffffff——引用块、未选中卡片、内嵌行在白天全部和卡片糊成一片。嵌套底色应取 --bg-base（浅色 #f1f5f9），或至少补一条描边。
窄屏命中区不足：桌面按钮高 32px，直接搬到 390 宽偏小。窄屏一律 44px 高、纵向铺满，主操作在下（拇指区）。
