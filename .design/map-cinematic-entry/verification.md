# MAP 电影式登录与沉浸首页交接

**一句话**：按参考视频的全屏角色、身份圆环与雾白到黑场显影重做入口，替换已被用户否定的抽象轨道方案。
**谁该读**：产品、设计与接手维护的人。
**读完能做什么**：复核视频取舍、真实操作路径和验证边界。

## 参考与规格

原视频为 3840×2160、60fps、19.317 秒。rea-video 已拆成四个主要段落并由 Codex 逐镜看图复核。以原片约 8.8 秒的白雾核验、15.7 秒的黑场轮廓、18.6 秒的角色工作空间为直接锚点，不再使用左右分栏、巨幅营销标题和旋转球。

角色主视觉按原片截图独立生成，清除原品牌、原聊天框与角落贴纸，开眼帧压成约 130KB WebP，闭眼帧另行存放。界面文案、圆环、搜索、按钮、HUD 和转场由原生页面渲染，没有把截图当可交互界面。用户已明确选择“方向错了，按视频效果重做”；同目录 concept.png 是实施参考，不代表用户逐项审批。

| 对照点 | 实现与取舍 |

## 使用路径

打开登录页 → 输入现有账号 → 开始身份确认 → 核验通过 → 沉浸首页 → 搜索或快捷进入能力。
查看原有在办工作与目录：沉浸首页 → 展开工作台；返回：返回沉浸首页。

## 八维交接

| 维度 | 事实 |
|---|---|
| 入口 | 原登录与首页路由，手机与桌面共用；没有新增独立 Agent 或 API |
| 文档与决定 | 本记录保存视频锚点、取舍与核验事实，不在产品展示交付报告 |
| 契约与数据 | 权限、SSO 回跳、首次改密沿用现有契约；登录后的权限读取期间不再提前跳转 |
| 测试与证据 | 表单显隐、实际等待与失败恢复、仅 SSO、权限前不跳转、权限失败/异常恢复、减少动态效果均有交互回归；真实账号已走通本地登录、搜索、快捷知识库、工作台展开与返回 |
| 发布 | 独立分支预览；同提交 CI、真实预览与冒烟结论由交付消息给出；未发布生产 |
| 安全 | 未修改账户密码、权限或凭据；测试凭据不进源码、日志或报告 |
| 风险 | 外部 SSO 提供方与真实首次改密没有改变现有账号来测试；新增媒体文件必须与前端同提交发布 |
| 后续 | 保持“服务端已通过才展示核验成功”的因果约束；不得将中央搜索改成无真实接入的聊天发送框 |

## 视觉验收

原视频帧图、生成概念图与浏览器截图直接对照，检查角色位置、雾白明度、中央表单、圆环、MAP 大字、搜索区及移动裁切。上一版抽象轨道装置及其样式、旧概念图已移除。

IAB 实际 CSS 视口已按原片检查 1920×1080，并检查手机尺寸下无横向溢出。浏览器截图与原片帧图直接对照，已修正初版手机角色眼睛被裁掉及按钮换行问题。

本地浏览器经仅监听回环地址的临时代理访问主分支 API，属于真实业务联调；公网分支验证另行执行，不能混为同一证据。系统已有服务额度通知属于真实账户通知，本次未确认或清除通知。

## 转场连续性修订

用户认可整体方向后指出过渡像逐帧跳动。本轮保持构图，修复扫描环改变周期造成的角度跳变，改为同一时钟平滑变速；去掉角色曝光关键帧的静止平台，采用交叠曝光与统一镜头推进。登录成功文字使用同位置叠层淡化，图片预解码、首页预加载与浏览器快照淡化衔接实际路由；移除离场动态模糊，显影完成后释放临时图层。减少动态效果的系统偏好仍直接进入。

帧采样仅在显式附带 motionProfile=1 的诊断入口启用，不发送遥测或记录用户信息；requestAnimationFrame 的间隔用于发现主线程停顿，不能代表所有设备的 GPU 实际呈现帧率。实际预览复测结论见本轮交付消息。
