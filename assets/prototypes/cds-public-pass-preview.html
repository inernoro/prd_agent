每一跳拿什么凭据，失败如何关闭

A1 使用者 → MyCDS：现有登录会话 + 项目 / 资源权限 A2 管理员 → 审查：独立已验证管理员会话，绑定申请内容 A3 MyCDS → 网关：实例专属受限凭据 + 带期限的策略 A4 MyCDS → 数据库：受限账号管理凭据，创建每证临时账号 A5 数据库工具 → 目标库：临时账号 + 随机密码 + TLS + 来源 IP
故障用户看到网络 / 数据处理
角色不符、审批拒绝未放行、原因、申请编号、恢复方式无公网入口、无写操作

到期 / 撤销 / 主控重启已到期、已断连独立期限关闭现有连接，重启不续期
账号回收失败入口已关闭，账号回收待管理员处理先关闭通道再报警，后台重试回收

真实 IP 只来自可信入口；不能信任客户端任填的请求头。TCP 转发携带的来源必须由可信隧道校验，不能把网关地址直接放入白名单当作用户 IP。

三个角色各自拿到什么

使用者

连接页 → 申请 → 复制 → 放行 → 数据库客户端验证 → 拿到可用连接和到期时间。

终点：真的连接成功
产品 / 运营

查看申请状态和审计编号 → 核对数据范围 → 获得可解释的通过或拒绝结果。

终点：范围与结果可核对
管理员 / 开发

审查身份与权限 → 批准指定范围 → 验证结果 → 撤销 → 获得申请、审批、连接及回收记录。

终点：有证据的关闭与回收

“请求已入队”“API 返回成功”或“复制成功”均不代表已连接。客户端实测和权限边界确认才到达终点。

验收：不能只看一个绿色提示
