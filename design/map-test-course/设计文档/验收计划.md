# MAP 课程 · 自动化测试实践 · 验收计划（V3）

八种验收手段都适用。本稿有 16 个画面（需要对照图与视觉）、9 个交接场景覆盖的关键操作（需要流程）、人工核对项、上线后要打开的页面与接口（需要冒烟），也有已知但还没证明的事（需要验收债务）。

| 手段 | 回答什么 | 谁做 | 什么时候 | 执行技能 |
|---|---|---|---|---|
| MECE 覆盖 | 该验的有没有漏、有没有重复 | 智能体 | 实现开始前 | `risk-matrix`、`acceptance-test-design` |
| 对照图 | 实现和稿件逐画面是否一致 | 智能体，人复核差异 | 部署到预览后 | `design-replication`、`cds-skeleton-review` |
| 视觉 | 位置、对齐、遮挡、深色、视口 | 智能体 | 与对照图同一轮 | `create-visual-test-to-kb` |
| 历史易错 | 双主题硬编码颜色、手机控制条堆叠、静止加载超过 2 秒 | 智能体 | 每轮验收 | `stable-smoke` |
| 流程 | 学员走完学一课与做一个练习 | 智能体 | 预览地址上 | `acceptance-scenario-orchestrator` |
| 人工 | 文案是否用学员的话、主动作是否唯一 | 人 | 签收前 | `acceptance-checklist` |
| 冒烟 | 课程与练习接口、两个页面能否打开 | 自动化 | 每次部署后 | `smoke-test` |
| 验收债务 | 真实评审耗时、经验值口径等未证明项 | 智能体 | 每轮结束 | `acceptance-debt-loop` |

## MECE 覆盖

六个维度都有验收项：正确性（A-13 至 A-16、A-18、A-19、A-23、A-24、A-26、A-27、A-29、A-38）、兼容性（A-01 至 A-04、A-06）、用户体验（A-05、A-09、A-11、A-12、A-17、A-21、A-22、A-25、A-28、A-32 至 A-34、A-36、A-37、A-39、A-40）、性能容量（A-20，另有一条真实耗时风险写了理由）、安全合规（A-10、A-30）、运维部署（A-07、A-08、A-31、A-35）。

## 对照图与视觉

用 `设计文档/演示数据.json` 在实现的预览地址打开每个画面（`design.json.screens[].impl`），桌面 1280×800 与手机 375×812、浅色与深色各一张，与稿件同画面并排，逐区块（顶栏、目录栏、材料区、底部练习条、工作台、步骤栏）写差异并标「有意 / 问题」。

## 流程

1. 学一课：学习中心 → 课程横幅 → 第 1 课视频（从 0:09 继续）→ 点逐字稿跳转 → 切 PDF（第 2 页）→ 切图文读到底 → 目录勾选、顶部「已学 1/5 课」；
2. 做练习：练习票选练习 → 评审（日志逐行、旗标、预计剩余、模型名）→ 判断 4 处（故意误采纳第 3 条）→ 复测失败 → 回到判断看反馈 → 改判 → 复测通过 → 提交交付 → 回课程看到「已完成」；
3. 续上：评审中途回课程，路线支线「进行中」→「接着做」回到同一次练习。

## 通过标准

全部验收项有结论与证据；对照图无标「问题」的差异；流程三条在预览地址跑通且截图里能看到产物（交付说明、完成页、目录勾选）。
