# MAP 课程 · 自动化测试实践 · 目标与验收（V3）

每个目标写「怎么算做到」和对应的验收项编号；验收项全文见 `design.json` 的 `acceptance`，交接以根目录《交接清单.md》为准。

| 目标 | 怎么算做到 | 验收项 |
|---|---|---|
| G-01 学员在学习中心找到课程，知道从哪一课接着学 | 学习中心有课程区，课程卡给出进度与下一课，点击直达；试运行标记可见 | A-07、A-11、A-36 |
| G-02 一课的视频、PDF 教材、图文三种材料由学员自选，进度能接上 | 三种材料在同一处切换，缺的材料说明原因；视频从上次位置继续、PDF 到上次的页、图文读完记下；地址记住课与材料 | A-12 至 A-20、A-37 |
| G-03 选一个练习，亲手走完检查 → 判断 → 修复 → 复测 → 交付 | 三个练习任选；Agent 运行过程可见；逐条判断有证据、驳回要理由；复测判错会指出哪条错；交付说明三段式；完成后课程里记为已完成 | A-21 至 A-31、A-38 至 A-40 |
| G-04 手机上也能学、能练 | 375 宽无横向溢出，进内容前只有一条控制栏，主动作吸底 | A-06、A-33、A-34 |
| G-05 出错时学员知道发生了什么、能接着做 | 评审失败、加载失败都说明结果、已保存的进度和下一步 | A-09、A-32、A-35 |

框架规则 R-01 至 R-10 对应 A-01 至 A-10，逐条在自检中通过。
