# MAP 课程 · 自动化测试实践 · 交付说明（V2）

## V2 相对 V1

功能与数据契约不变，界面整体重画为「检验台」：课程路线（5 站 + 练习支线）、书桌（主舞台 + 伴读栏 + 练习票）、练习控制台（日志、工单盖章、复测记分板、交付单、合格证）。除 AppShell 导航与作为按钮载体的 design/Button 外，不再使用 PageHeader、SegmentedTabs、加载组件等现成部件。数据新增两个字段：课程摘要 `lessonShortTitles`（课程卡迷你路线）、每课 `keyPoints`（伴读栏要点）。

## 这一版交付什么

在学习中心新增「课程」区，以及课程页、练习页两个子页。示例内容是一门《自动化测试实践》：5 课、2 段视频、8 页 PDF 教材、5 篇图文、3 个练习（代码评审、视觉验收、审生成的单元与联合测试），全部为虚构演示数据（`设计文档/演示数据.json`）。

## 位置与路径

- 【位置】我的 → 学习中心 → 课程区
- 【路径】登录后打开学习中心 → 点课程卡「自动化测试实践」→ 进入第 1 课；在课程页底部点「开始练习」或在左栏练习列表里任选一个
- 【预览】原型画面见稿件画面清单：`center`、`lesson-video`、`lesson-pdf`、`lesson-article`、`practice-*`、`phone-*`

## 实现要点

1. 源码差异 `设计文档/源码差异.diff`（相对正式基线的整份差异），可在基线 2c230222 上直接 `git apply`（本机已核对），`pnpm exec tsc --noEmit` 与 `pnpm exec eslint`（改动文件）通过：
   - 改动：`app/navRegistry.tsx`（注册课程页与练习页两条子路由）、`pages/learning-center/LearningCenterPage.tsx`（插入课程区）；
   - 新增：`pages/learning-course/` 下的课程页、练习页及组件（路线、书桌、三种材料、练习票、控制台、工单）、样式、注册表与类型，`services/real/learningCourses.ts`。
2. 后端需要新增的接口（前端已按这些契约调用，统一经 `apiRequest`）：`GET /api/learning/courses`、`GET /api/learning/courses/:id`、`PUT .../lessons/:lessonId/progress`、`GET .../practices/:pid`、`POST /api/learning/practice-runs`、`GET /api/learning/practice-runs/:id`、`POST .../review | decisions | reopen | delivery`。
3. 练习的评审与复测走服务端 Run（离开页面不取消），Agent 调用经统一网关并回传模型名与平台；判定口径（每条意见该采纳还是驳回、判错时的反馈文案、复测检查与意见的对应关系）只在服务端，演示数据里的 `serverJudging` 是口径样例。
4. 课程数据带 `wip: true`，学习中心课程卡与课程页显示「试运行」；真人在预览域名验收后去掉。
5. 只用于原型的文件不进源码差异：`src/main.tsx`、`src/env.ts`（模拟服务端）、`src/fixtures.ts`、`src/assets/`、`tools/`。
