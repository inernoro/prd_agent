# 目标与验收

每个目标写「怎么算做到」和对应验收项；验收项的规则、检查方式与通过标准以 `design.json.acceptance` 为准。

| 目标 | 怎么算做到 | 验收项 |
| --- | --- | --- |
| T-01 一页两件事 | 3 秒内找到「签发新 Key」和最近签发的 Key；从项目卡进来只看该项目相关 Key | AK-01、AK-02、AK-03 |
| T-02 签发前看清后果 | 说明栏写清能访问、能做、不能做、何时失效和风险；回执与详情逐字一致 | AK-04 到 AK-10 |
| T-03 有效期 | 默认永久；可选期限并显示具体时间；用户选的到期日不随使用推迟 | AK-11、AK-12 |
| T-04 来源 | 三类来源互不包含；来源链可读；历史 Key 不推测 | AK-13 到 AK-16 |
| T-05 状态与吊销 | 状态与鉴权一致；吊销确认、即时、留痕；结果不明不重复提交 | AK-17 到 AK-20、AK-23 |
| 基础规则 | 框架 FW-CDS-UI V3 与窄屏可达 | R-01、R-02、R-03、R-04、R-07、R-11、AK-21、AK-22 |
