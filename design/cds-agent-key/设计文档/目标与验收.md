# 目标与验收

每个目标写「怎么算做到」和对应验收项；验收项的规则、检查方式与通过标准以 `design.json.acceptance` 为准。

| 目标 | 怎么算做到 | 验收项 |
| --- | --- | --- |
| T-01 一页两件事 | 3 秒内找到「签发新 Key」和最近签发的 Key；从项目卡进来只看该项目相关 Key | A-07、A-08、A-09 |
| T-02 签发前看清后果 | 说明栏写清能访问、能做、不能做、何时失效和风险；回执与详情逐字一致 | A-10 到 A-16 |
| T-03 有效期 | 默认永久；可选期限并显示具体时间；用户选的到期日不随使用推迟 | A-17、A-18 |
| T-04 来源 | 三类来源互不包含；来源链可读；历史 Key 不推测 | A-19 到 A-22 |
| T-05 状态与吊销 | 状态与鉴权一致；吊销确认、即时、留痕；结果不明不重复提交 | A-23 到 A-26、A-29 |
| 基础规则 | 框架 FW-CDS-UI V3 与窄屏可达 | A-01、A-02、A-03、A-04、A-05、A-06、A-27、A-28 |
