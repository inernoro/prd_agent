## 源码差异覆盖什么

- 后端：签发通道写 `issuedVia`（页面、机器接口、Agent 申请批准、用户凭据自助、设备接入、建项目六条）；新增 `GET /api/global-agent-keys/catalog` 合并列表；鉴权与列表共用 `agentKeyUsability`；页面签发支持 `expiresAt`，项目 Key 写 `expiryMode=fixed` 不续期。
- 前端：系统设置「Agent Key」页改版；新增说明函数 `describeAgentKey`；项目卡跳转本页；删除旧弹窗与 `AgentKeyScopePanel`。
- 测试：`cds/tests/routes/agent-key-catalog.test.ts`（12 条）、`cds/tests/web/agent-key-catalog.test.ts`（11 条）。
- 应用后还要做两步（差异里没有包含，因为它们改的是技能包文件）：`pnpm --dir cds sync:menu-routes` 重新生成 `.claude/skills/cds/reference/menu.md`（任务注册表里「AI Access Key」改成了「Agent Key」），再运行 `python .claude/skills/cds/scripts/refresh_manifest.py` 刷新技能清单哈希。

## 模块差异（R-04）

- 本模块在系统设置的「接入」组；签发弹窗用公共 `Dialog`（`frame` 布局），确认用公共 `ConfirmAction`。
- 新增来源标签三种样式：用户签发（凹陷底加细边）、AI Agent 签发（`info` 语义色）、来源未记录（虚线边）。均取根主题令牌，两个主题都已核对。
- 风险标记三档用 `ok`、`warn`、`bad` 语义色，不新增颜色。
