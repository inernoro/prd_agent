# 目标与验收（V1）

> 目标与验收项的唯一来源是 `design.json`（goals、acceptance），交接以程序生成的 `交接清单.md` 为准。本页按目标给人读的摘要。

1. **最快路径**：选产出（视频 / 网页）与模板，放稿件，可选一句要求，快捷生成。没有可用稿件时按钮不可用并说明原因。
2. **附件清楚**：收起时一行摘要 + 两个胶囊 + 「+N」；展开分组管理、失败项置顶并可单项重试或移除；发送后可回看。
3. **排队、后台与恢复**：排队写位置与预计开始；生成写阶段、进度与剩余；离开后从作品列表回到同一任务。
4. **失败保住已有工作**：单幕失败只重做那一幕；超时保留已完成部分并从断点继续。
5. **成品能播、能发、能追溯**：有声播放器带字幕与重点刻度；发布失败可重试且成品仍可播；发布成功定位到网页托管记录。
6. **网页产出**：大纲逐节出现，完成后桌面 / 手机预览，重点定位到对应一节。
7. **手机可用**：创作 / 预览切换，底部动作可达，头部与播放器不挤压，30 条作品稳定。
8. **独立入口**：百宝箱有独立卡片，navRegistry 注册带 wip。
9. **未来逐幕创作**：只给概念稿（设置面板、逐幕编辑与版本），不在本稿交接实现。
