# 快速创作 · 交付说明（V1）

## 这一版交付了什么

快速创作智能体的快捷版：一份文档 + 一个模板，得到**能播放的视频**或**能浏览的网页**，并发布到网页托管。原型由 prd-admin 正式代码在基线 `949bfa27` 上构建，页面挂在正式 AppShell 里。

| 范围 | 内容 |
|---|---|
| 当前快捷版（交接实现） | 产出切换（视频 / 网页）、模板卡（真实成品帧）、附件托盘、可选一句要求、快捷生成；排队、生成、单幕失败、整条超时；成片播放器（字幕、重点、上一幕 / 下一幕）、网页预览（桌面 / 手机）；发布失败与重试、发布成功定位到网页托管；我的作品（30 条）；手机端；百宝箱入口 |
| 未来逐幕创作（只给概念稿，不交接） | 设置面板（语速两档、时长、重点预告、受众，口语识别并注明来源）、逐幕调整（旁白与字幕同一幕、改动提示、单幕版本撤回、按幕定位播放）、作品空间与模板库分类 |

## 怎么看

画面清单里每个画面对应一个状态，入口地址以 `#/` 开头。重点画面：

1. `attachments` / `attachments-expanded`：附件再多也只占一行，展开后分组管理、失败项置顶。
2. `queued` → `generating` → `done-video`：排队、逐阶段生成、成片。
3. `failed-scene` / `timeout`：失败只重做没完成的部分。
4. `publish-failed` → `published` → `hosting`：发布失败可重试，成功后落到网页托管记录。
5. `web-generating` / `web-done`：网页产出。
6. `phone-*`：手机端。

## 实现方怎么接

- 整份应用 `设计文档/源码差异.diff`（12 个文件：新页面目录、接口封装、navRegistry 与 toolboxStore 登记）。在基线上 `git apply` 后 `tsc --noEmit` 退出码 0，相关文件 ESLint 零告警。
- 接口约定见 `services/real/quickCreation.ts`：模板、作品、任务（创建 / 查询 / 重试 / 发布）、附件（上传 / 知识库 / 重新读取）。任务在服务端排队执行，页面每 1.5 秒查询一次，直到终态；正式实现可换成推送，页面接口不变。
- 演示数据：`设计文档/演示数据.json`（由 `src/fixtures.ts` 导出），原型与实现取证用同一份。
- 交接以 `交接清单.md` 为准（程序生成，按目标列验收项与回复模板）。

## 自检结果

- 作者自检 41 / 41（`checks/result.json`）：10 条测量项由 `tools/self-check.mjs` 在还原的 CDS 预览容器里计算，30 条人工 / 截图项逐画面走查并记录在 `tools/walkthrough.json`，5 条交互由 `tools/interact-check.mjs` 实际点击验证。
- 23 个画面 × 两个主题共 46 次打开，控制台与 CSP 报错 0 条。
- 手机 390 宽无整页横向溢出；本页新增可点元素触控高度不小于 44px（公共组件 SegmentedTabs 沿用正式实现，差异记为框架债务）。
- 对比度（实测，以 --bg-base 为底）：黑天正文 17.19、次要 11.24；白天正文 14.89、次要 7.98，均高于 4.5。

## 已知边界

1. 团队并发上限（4）、单幕配音超时（3 分钟）与整条超时（15 分钟）是占位值，需按服务端能力定。
2. 「从知识库选择」在原型里直接加入示例文档；正式实现复用 MD 转网页 PPT 的知识库选择交互，建议抽成公共组件。
3. 原型里的网页托管与百宝箱是示意页；正式实现分别是 WebPagesPage（已支持 `?focusSite=`）与百宝箱，不需要改它们。
4. 视频的配音与合成服务、费用口径在实现前确认。
