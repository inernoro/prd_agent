# 一段可复制的选设计提示词

用当前项目中可分享的事实替换占位符。只保留当前设计适用的内容。没有可运行源码时注明可交付格式。需要严格对齐现有项目时附 [设计上下文包](design-context-pack.md)，提示词仍可独立读懂。

```text
请为【用户与场景】设计【对象与任务】。打开后用户需要【看见的信息】，能【主要操作】并得到【可观察的结果】。

落地环境是【实际框架、语言、样式与组件体系、包管理器】。请在【可编辑容器或文件】里工作，沿用【可复用的现有组件或起始代码】；【外壳、导航或父级滚动边界】由系统提供。容器范围是【CSS 宽度或大小规则、滚动归属、主题或响应式要求】。可以按【预览命令或设计工具入口】查看。若工具支持相同技术栈，请交回可直接接入的源码；若不支持，请交回可编辑设计源、素材与关键状态。

必须保留【产品能力、关键交互和已确认的内容】。请自由探索【可创新的布局、构图、动效或表达方式】，也可以提出超出现有风格的方案并说明取舍。可选参考是【用户指定的颜色、组件或风格页面，注明必须遵守或仅作灵感】。

请展示【实际会受设计影响的状态、窄屏或长内容，以及操作前后】。如涉及保存、生成或重新打开，请说明预期结果和数据假设。交回【选定环境可编辑的代码或稿件、必要素材、状态入口和版本】；使用示例数据表达真实语义。
```

当任务仅需要自由探索时，这一段即可，选填参考和非必要交付项可以删掉。复杂状态按需要补充数据规模、加载、错误、交互时序与适用设备。设计选定后，用真实用户入口和业务结果验收。
